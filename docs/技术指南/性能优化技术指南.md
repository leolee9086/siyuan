## 2. 代码备份操作手册

### 2.1 使用 Git 分支备份

#### 2.1.1 创建备份分支

**基本命令**:
```bash
# 创建并切换到备份分支
git checkout -b backup/optimization-<feature-name>-<date>

# 示例：为搜索功能优化创建备份
git checkout -b backup/optimization-search-20260126
```

**命令说明**:
- `-b`: 创建新分支并切换到该分支
- 分支命名格式: `backup/optimization-<功能名>-<日期>`
- 日期格式: YYYYMMDD

**推送到远程仓库**:
```bash
# 推送备份分支到远程
git push origin backup/optimization-<feature-name>-<date>

# 示例
git push origin backup/optimization-search-20260126
```

#### 2.1.2 验证备份

**检查分支状态**:
```bash
# 查看当前分支
git branch

# 查看所有分支（包括远程）
git branch -a

# 查看分支详细信息
git show-branch
```

**验证备份内容**:
```bash
# 查看备份分支的提交历史
git log backup/optimization-<feature-name>-<date>

# 比较备份分支和当前分支
git diff backup/optimization-<feature-name>-<date>

# 查看备份分支的文件列表
git ls-tree -r backup/optimization-<feature-name>-<date> --name-only
```

#### 2.1.3 从备份恢复

**恢复整个分支**:
```bash
# 切换回备份分支
git checkout backup/optimization-<feature-name>-<date>

# 创建新的工作分支
git checkout -b optimization-<feature-name>-retry
```

**恢复特定文件**:
```bash
# 从备份分支恢复单个文件
git checkout backup/optimization-<feature-name>-<date> -- path/to/file.go

# 从备份分支恢复整个目录
git checkout backup/optimization-<feature-name>-<date> -- path/to/directory/
```

### 2.2 创建文件副本备份

#### 2.2.1 Windows 环境

**复制单个文件**:
```cmd
REM 复制文件并添加 .backup 后缀
copy source_file.go source_file.go.backup

REM 复制文件到备份目录
copy source_file.go backup\source_file.go.20260126
```

**复制整个目录**:
```cmd
REM 复制目录及其所有内容
xcopy /E /I /H source_directory backup\source_directory.20260126

REM 参数说明：
REM /E - 复制目录和子目录，包括空目录
REM /I - 如果目标不存在，假定目标是目录
REM /H - 复制隐藏文件和系统文件
```

**创建压缩备份**:
```powershell
# 使用 PowerShell 创建 ZIP 备份
Compress-Archive -Path source_directory -DestinationPath backup\source_directory.20260126.zip

# 添加时间戳
$timestamp = Get-Date -Format "yyyyMMdd-HHmmss"
Compress-Archive -Path source_directory -DestinationPath "backup\source_directory.$timestamp.zip"
```

#### 2.2.2 Linux/macOS 环境

**复制单个文件**:
```bash
# 复制文件并添加 .backup 后缀
cp source_file.go source_file.go.backup

# 复制文件到备份目录
cp source_file.go backup/source_file.go.$(date +%Y%m%d)
```

**复制整个目录**:
```bash
# 复制目录及其所有内容
cp -r source_directory backup/source_directory.$(date +%Y%m%d)

# 保留文件属性
cp -a source_directory backup/source_directory.$(date +%Y%m%d)
```

**创建压缩备份**:
```bash
# 创建 tar.gz 备份
tar -czf backup/source_directory.$(date +%Y%m%d).tar.gz source_directory

# 创建 zip 备份
zip -r backup/source_directory.$(date +%Y%m%d).zip source_directory
```

```bash
# 运行测试
```

**功能验证**:


## 3. 基准测试工具使用

### 3.1 Go 基准测试命令参考

#### 3.1.1 基本命令

**运行所有基准测试**:
```bash
go test -bench=.
```

**运行特定基准测试**:
```bash
# 运行名称匹配的基准测试
go test -bench=BenchmarkSearchBlocks

# 使用正则表达式匹配
go test -bench=BenchmarkSearch.*
```

**指定运行时间**:
```bash
# 每个基准测试运行 10 秒
go test -bench=. -benchtime=10s

# 运行指定次数
go test -bench=. -benchtime=100x
```

#### 3.1.2 内存分析参数

**启用内存统计**:
```bash
# 显示内存分配统计
go test -bench=. -benchmem
```

**输出示例**:
```
BenchmarkSearchBlocks-8    1000000    1234 ns/op    512 B/op    10 allocs/op
```

**输出说明**:
- `1000000`: 运行次数
- `1234 ns/op`: 每次操作耗时（纳秒）
- `512 B/op`: 每次操作分配的字节数
- `10 allocs/op`: 每次操作的内存分配次数

#### 3.1.3 CPU 分析参数

**生成 CPU profile**:
```bash
# 生成 CPU 性能分析文件
go test -bench=. -cpuprofile=cpu.prof

# 指定输出目录
go test -bench=. -cpuprofile=profiles/cpu.prof
```

**生成内存 profile**:
```bash
# 生成内存性能分析文件
go test -bench=. -memprofile=mem.prof

# 同时生成 CPU 和内存 profile
go test -bench=. -cpuprofile=cpu.prof -memprofile=mem.prof
```

### 3.2 基准测试参数说明

#### 3.2.1 并发测试参数

**指定并发数**:
```bash
# 使用 4 个 CPU 核心
go test -bench=. -cpu=4

# 测试多个并发级别
go test -bench=. -cpu=1,2,4,8
```

**并发基准测试**:
```bash
# 运行并发基准测试
go test -bench=BenchmarkParallel -cpu=1,2,4,8
```

#### 3.2.2 输出控制参数

**详细输出**:
```bash
# 显示详细信息
go test -bench=. -v

# 显示测试名称
go test -bench=. -benchmem -v
```

**输出到文件**:
```bash
# 保存基准测试结果
go test -bench=. -benchmem > benchmark_results.txt

# 追加到文件
go test -bench=. -benchmem >> benchmark_results.txt
```

### 3.3 结果保存和对比方法

#### 3.3.1 保存基准测试结果

**标准格式保存**:
```bash
# 保存优化前的结果
go test -bench=. -benchmem > benchmarks/before.txt

# 保存优化后的结果
go test -bench=. -benchmem > benchmarks/after.txt
```

**带时间戳保存**:
```bash
# Linux/macOS
go test -bench=. -benchmem > "benchmarks/result_$(date +%Y%m%d_%H%M%S).txt"

# Windows PowerShell
$timestamp = Get-Date -Format "yyyyMMdd_HHmmss"
go test -bench=. -benchmem > "benchmarks\result_$timestamp.txt"
```

#### 3.3.2 多次运行保存

**运行多次并保存**:
```bash
# 运行 10 次基准测试
for i in {1..10}; do
  go test -bench=. -benchmem >> benchmarks/multiple_runs.txt
done

# Windows CMD
for /L %i in (1,1,10) do go test -bench=. -benchmem >> benchmarks\multiple_runs.txt
```

```bash

```

#### 6.1.3 统计分析选项

**配置统计参数**:
```bash
# 设置显著性水平（默认 0.05）

# 设置最小样本数（默认 5）
benchstat -min=10 before.txt after.txt

# 显示所有结果（包括不显著的）

```

**输出格式选项**:
```bash

# HTML 格式输出

```

### 6.2 统计分析方法

#### 6.2.1 计算性能提升百分比

**手动计算公式**:
```
性能提升 = (优化前时间 - 优化后时间) / 优化前时间 × 100%

示例：
优化前：1234 ns/op
优化后：850 ns/op
性能提升 = (1234 - 850) / 1234 × 100% = 31.1%
```

**使用 benchstat 自动计算**:
```bash
# benchstat 会自动计算并显示 delta（变化百分比）
benchstat before.txt after.txt

# 输出中的 delta 列显示性能变化
# 负值表示性能提升（时间减少）
# 正值表示性能下降（时间增加）
```

#### 6.2.2 评估统计显著性

**理解 p 值**:
- `p < 0.05`: 结果具有统计显著性（95% 置信度）
- `p < 0.01`: 结果具有高度统计显著性（99% 置信度）
- `p ≥ 0.05`: 结果可能是随机波动，不具有统计显著性

**benchstat 输出解读**:
```
name              old time/op  new time/op  delta
SearchBlocks-8    1.23µs ± 2%  0.85µs ± 1%  -30.89%  (p=0.000 n=10+10)
                  ↑            ↑            ↑        ↑
                  优化前       优化后       变化%    统计信息
```

**统计信息说明**:
- `± 2%`: 标准差（变异系数）
- `p=0.000`: p 值（< 0.001 显示为 0.000）
- `n=10+10`: 样本数量（优化前 10 次，优化后 10 次）

### 6.3 内存分析工具

#### 6.3.1 内存泄漏检测

**使用 pprof 检测内存泄漏**:
```bash
# 生成堆内存快照
go test -memprofile=mem1.prof
# ... 运行一段时间后 ...
go test -memprofile=mem2.prof

# 比较两个快照
go tool pprof -base=mem1.prof mem2.prof
```

**使用 runtime 包监控内存**:
```bash
# 在代码中添加内存监控
# 然后运行程序并观察内存使用
go run main.go
```

#### 6.3.2 内存分配分析

**分析内存分配热点**:
```bash
# 生成内存分配 profile
go test -bench=. -memprofile=mem.prof -memprofilerate=1

# 分析分配最多的函数
go tool pprof -alloc_space -top10 mem.prof

# 分析分配次数最多的函数
go tool pprof -alloc_objects -top10 mem.prof
```

**生成内存分配报告**:
```bash
# 文本格式报告
go tool pprof -alloc_space -text mem.prof > memory_alloc_report.txt

# 可视化报告
go tool pprof -alloc_space -http=:8080 mem.prof
```

#### 6.3.3 内存使用优化验证

**对比内存使用**:
```bash
# 保存优化前的内存数据
go test -bench=. -benchmem > mem_before.txt

# 保存优化后的内存数据
go test -bench=. -benchmem > mem_after.txt

# 使用 benchstat 比较
benchstat mem_before.txt mem_after.txt
```

**关注的内存指标**:
- `B/op`: 每次操作分配的字节数（越小越好）
- `allocs/op`: 每次操作的内存分配次数（越少越好）
- 内存分配减少 > 30% 被认为是显著优化
