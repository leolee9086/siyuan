# 笔记内插件（In-Note Plugin）功能设计

## 概述

允许用户在笔记文档中使用 JavaScript 代码块定义前端插件，复用现有插件 API 和外部库管理机制。

---

## 核心设计

### 工作流程

```
用户文档(ext-type: plugin) → 前端编译器 → JS代码 → SecureModuleCreator → 插件实例
```

### 最小化改动清单

| 改动 | 说明 | 必要性 |
|------|------|--------|
| `inNotePlugin/compiler.ts` | 提取文档中的JS代码块 | ✅ 必须 |
| `inNotePlugin/loader.ts` | 复用SecureModuleCreator加载插件 | ✅ 必须 |
| `inNotePlugin/siyuanApi.ts` | 生成siyuan API的Blob URL | ✅ 必须 |

## 外部库管理

> 复用现有的 `app/src/util/code/` 模块，无需额外开发。

### 机制说明

1. **esm.sh CDN 重定向**
   - 裸模块自动重定向到 `https://esm.sh/<packageName>`
   - 例如 `import dayjs from "dayjs"` → `import dayjs from "https://esm.sh/dayjs"`

2. **用户许可确认**
   - 首次使用外部包时弹出确认对话框
   - 已确认的包缓存在 `PackagePermissionManager` 中，无需重复确认

3. **白名单配置**
   - `siyuan` 包：始终允许（通过 Blob URL 重定向）
   - 其他包：需用户确认或配置白名单

### 许可持久化方案

现有的 `PackagePermissionManager` 仅内存缓存，页面刷新后丢失。需要扩展持久化能力：

```typescript
// inNotePlugin/permissionManager.ts
const PERMISSION_KEY = "in-note-plugin-allowed-packages";

class PersistentPermissionManager extends PackagePermissionManager {
    constructor() {
        super();
        // 启动时从 localStorage 恢复
        const saved = localStorage.getItem(PERMISSION_KEY);
        if (saved) {
            JSON.parse(saved).forEach(pkg => this.cachePermission(pkg, true));
        }
    }
    
    cachePermission(packageName: string, allowed: boolean) {
        super.cachePermission(packageName, allowed);
        // 同步保存到 localStorage
        const packages = this.getAllAllowedPackages();
        localStorage.setItem(PERMISSION_KEY, JSON.stringify(packages));
    }
    
    getAllAllowedPackages(): string[] {
        return [...this.cache.entries()]
            .filter(([_, v]) => v)
            .map(([k]) => k);
    }
}
```

**设计要点**：
- 使用 localStorage 与插件启用状态保持一致
- 仅存储"允许"的包，"拒绝"的包每次重新确认
- 不修改现有 `PackagePermissionManager`，通过子类扩展

### 配置示例

```typescript
const creator = new SecureModuleCreator({
```

## 高级特性（参考saccompiler）

### 1. 自定义 CDN 配置

插件可通过 `import.meta.cdn` 指定CDN服务器：

```javascript
import.meta.cdn = 'https://cdn.jsdelivr.net/npm/'

import dayjs from "dayjs"  // → https://cdn.jsdelivr.net/npm/dayjs
```

### 2. 跨笔记模块引用

使用 `@note:模块名` 语法引用其他笔记定义的模块：

```javascript
// 文档A: 定义工具模块
// import.meta.module = 'myUtils'
export function hello() { return "Hello!" }

// 文档B: 引用文档A的模块
import { hello } from "@note:myUtils"
```

实现方式：
1. SQL查询所有 `ext-type: plugin` 文档
2. 解析 `import.meta.module` 获取模块名
3. 构建模块名 → Blob URL 映射表
4. 重写 `@note:xxx` 为对应的 Blob URL

### 3. 调试支持

编译后的代码添加 `sourceURL` 便于调试：

```javascript
// 编译后
import { Plugin } from "blob:..."
export default class MyPlugin extends Plugin { ... }
//# sourceURL=note-plugin://文档ID/文档标题
```

### 4. 立即执行模式

文档无需注册为插件，只需添加 `immediate` 标记即可自动执行：

```javascript
import.meta.immediate = true

console.log("这段代码会在加载时立即执行")
```

## 核心实现

### 1. 前端编译器

```typescript
// inNotePlugin/compiler.ts
export async function 编译文档(docId: string): Promise<string> {
    const blocks = await fetchSyncPost("/api/block/getChildBlocks", { id: docId });
    const 代码片段: string[] = [];
    
    for (const block of blocks.data) {
        if (block.type === "c") {
            const { data } = await fetchSyncPost("/api/block/getBlockKramdown", { id: block.id });
            const match = data.kramdown.match(/^```(?:javascript|js)\n([\s\S]*?)\n```/);
            if (match) 代码片段.push(match[1]);
        }
    }
    
    return 代码片段.join("\n\n");
}
```

### 2. Siyuan API 模块生成

```typescript
// inNotePlugin/siyuanApi.ts
import { API } from "../plugin/API";

let siyuanApiUrl: string | null = null;

export function getSiyuanApiUrl(): string {
    if (siyuanApiUrl) return siyuanApiUrl;
    
    const code = `
const API = window._siyuanPluginAPI;
export const Plugin = API.Plugin;
export const showMessage = API.showMessage;
export const fetchPost = API.fetchPost;
export const Dialog = API.Dialog;
export const Menu = API.Menu;
export const Setting = API.Setting;
export const Constants = API.Constants;
export default API;
`;
    
    (window as any)._siyuanPluginAPI = API;
    siyuanApiUrl = URL.createObjectURL(new Blob([code], { type: "application/javascript" }));
    return siyuanApiUrl;
}
```

### 3. 插件加载器

```typescript
// inNotePlugin/loader.ts
import { Plugin } from "../plugin";
import { SecureModuleCreator } from "../util/code/executor";
import { getSiyuanApiUrl } from "./siyuanApi";
import { 编译文档 } from "./compiler";

export async function 加载笔记内插件(app: App, docId: string, displayName: string) {
    const code = await 编译文档(docId);
    
    const creator = new SecureModuleCreator({
        allowedPackages: ["siyuan"],
        moduleRedirectConfig: {
            defaultServer: "https://esm.sh",
            packageRedirects: { "siyuan": getSiyuanApiUrl() },
            enabled: true,
            bareModulesOnly: true
        }
    });
    
    const module = await creator.createSecureModule(code);
    if (module.hasError) throw new Error(module.error);
    
    const PluginClass = module.moduleExport?.default;
    if (!(PluginClass?.prototype instanceof Plugin)) {
        throw new Error("插件必须 export default 一个继承 Plugin 的类");
    }
    
    const plugin = new PluginClass({ app, name: `in-note-${docId}`, displayName, i18n: {} });
    await plugin.onload();
    plugin.onLayoutReady();
    
    return { plugin, cleanup: module.cleanup };
}

export function 卸载笔记内插件(state: { plugin: Plugin; cleanup: () => void }) {
    state.plugin.onunload();
    state.cleanup();
}
```

### 4. 插件管理器

```typescript
// inNotePlugin/manager.ts
const STORAGE_KEY = "in-note-plugins";

interface PluginState {
    docId: string;
    displayName: string;
    plugin: Plugin;
    cleanup: () => void;
}

class InNotePluginManager {
    private plugins = new Map<string, PluginState>();
    private app: App;
    
    init(app: App) {
        this.app = app;
        this.loadEnabledPlugins();
    }
    
    getEnabledPluginIds(): string[] {
        return JSON.parse(localStorage.getItem(STORAGE_KEY) || "[]");
    }
    
    private saveEnabledPluginIds(ids: string[]) {
        localStorage.setItem(STORAGE_KEY, JSON.stringify(ids));
    }
    
    async loadEnabledPlugins() {
        for (const docId of this.getEnabledPluginIds()) {
            try {
                const title = await this.getDocTitle(docId);
                await this.enablePlugin(docId, title);
            } catch (e) {
                console.error(`加载插件 ${docId} 失败:`, e);
            }
        }
    }
    
    async enablePlugin(docId: string, displayName: string) {
        if (this.plugins.has(docId)) return;
        
        const state = await 加载笔记内插件(this.app, docId, displayName);
        this.plugins.set(docId, { docId, displayName, ...state });
        
        const ids = this.getEnabledPluginIds();
        if (!ids.includes(docId)) {
            this.saveEnabledPluginIds([...ids, docId]);
        }
    }
    
    disablePlugin(docId: string) {
        const state = this.plugins.get(docId);
        if (!state) return;
        
        卸载笔记内插件(state);
        this.plugins.delete(docId);
        
        const ids = this.getEnabledPluginIds().filter(id => id !== docId);
        this.saveEnabledPluginIds(ids);
    }
    
    async reloadPlugin(docId: string) {
        const state = this.plugins.get(docId);
        if (!state) return;
        
        this.disablePlugin(docId);
        await this.enablePlugin(docId, state.displayName);
    }
    
    private async getDocTitle(docId: string): Promise<string> {
        const { data } = await fetchSyncPost("/api/block/getBlockInfo", { id: docId });
        return data.rootTitle || docId;
    }
}

export const inNotePluginManager = new InNotePluginManager();
```

## 安全考虑

| 风险 | 缓解措施 |
|------|----------|
| 恶意外部包 | 用户首次导入需确认，已拒绝的包会被记住 |
| 代码执行风险 | 只有用户主动注册的文档才会作为插件执行 |
| 资源泄漏 | `onunload` 生命周期确保清理，Blob URL 自动回收 |
