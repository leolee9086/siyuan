# Vamana构建性能优化方案

当前：100K向量 164秒，目标：<60秒

## 瓶颈1：greedySearch没用快速距离

**当前代码 (288行)**：
```go
dist := idx.distanceToQuery(neighborID, query)
// 调用 euclideanDistance，没利用预计算范数
```

**优化**：用`fastDistanceToQuery`，需要预计算查询范数
```go
// buildNodeWithScratch 开头
queryNormSq := computeNormSquare(vector)
// greedySearch 改为接受 queryNormSq
dist := idx.fastDistanceToQuery(neighborID, query, queryNormSq)
```

## 瓶颈2：robustPrune分配临时数组

**当前代码 (320-326行)**：
```go
occludeFactor := make([]float32, n)
lastChecked := make([]int, n)
resultPos := make([]int, 0, maxDegree)
```
每次调用都分配3个slice，100K节点 = 30万次GC压力

**优化**：复用SearchScratch
```go
type SearchScratch struct {
    // 新增 robustPrune 复用缓冲
    OccludeFactor []float32
    LastChecked   []int
    ResultPos     []uint32
}

func (idx *VamanaIndex) robustPruneWithScratch(nodeID uint32, candidates []Neighbor, maxDegree int, alpha float32, scratch *SearchScratch) []uint32 {
    // 复用 scratch 的缓冲区
    n := len(candidates)
    if cap(scratch.OccludeFactor) < n {
        scratch.OccludeFactor = make([]float32, n)
    }
    scratch.OccludeFactor = scratch.OccludeFactor[:n]
    // ... 类似处理其他
}
```

## 瓶颈3：8路循环展开 + 预取

**当前**：4路展开
**优化**：8路展开 + 手动预取

```go
func dotProduct(a, b []float32) float32 {
    n := len(a)
    var s0, s1, s2, s3, s4, s5, s6, s7 float32
    
    i := 0
    for ; i <= n-8; i += 8 {
        s0 += a[i] * b[i]
        s1 += a[i+1] * b[i+1]
        s2 += a[i+2] * b[i+2]
        s3 += a[i+3] * b[i+3]
        s4 += a[i+4] * b[i+4]
        s5 += a[i+5] * b[i+5]
        s6 += a[i+6] * b[i+6]
        s7 += a[i+7] * b[i+7]
    }
    // 处理剩余...
    return s0+s1+s2+s3+s4+s5+s6+s7
}
```
