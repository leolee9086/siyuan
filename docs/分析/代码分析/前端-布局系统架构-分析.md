# 前端布局系统架构分析

## Dock 系统现有架构

### 已实现的 Registry + Factory 模式

> [!TIP]
> 哥哥已在 Dock 系统中实现了 Registry + Factory 双层架构，可直接复用到 Tab 系统

#### 1. dock.registry.ts - 类型占用注册表

**目的**：解决多个 Dock 实例初始化顺序不确定时的类型去重问题

```typescript
// 全局注册表，存储在 SForge Symbol 属性下
function 获取类型注册表(): Map<string, TDockPosition>

// 核心 API
export function 注册类型(type: string, position: TDockPosition): boolean
export function 类型可用(type: string): boolean
export function 是本Dock的类型(type: string, position: TDockPosition): boolean
export function 注销类型(type: string, position: TDockPosition): void
```

**特点**：
- 使用 SForge 全局状态，避免模块级变量问题
- 所有权机制：只有所有者才能注销类型
- 提供英文别名导出

#### 2. dock.factory.ts - Model 工厂

**目的**：统一创建各类型 Dock Model 的入口点

```typescript
// 内置类型工厂表
const MODEL_FACTORIES: Record<string, ModelFactory> = {
    file: initFile,
    bookmark: initBookmark,
    tag: initTag,
    outline: initOutline,
    graph: initGraph,
    globalGraph: initGlobalGraph,
    backlink: initBacklink,
    inbox: initInbox,
    embedding_dock: initEmbeddingDock,
    cronjob: initCronjob,
};

// 统一创建入口
export const createModel = (options) => {
    // 1. 先查内置工厂
    const factory = MODEL_FACTORIES[options.type];
    if (factory) return factory(...);
    
    // 2. 处理 custom_list 特殊前缀
    if (options.type.startsWith("custom_list")) { ... }
    
    // 3. 回退到插件
    return initPlugin(app, tab, type);
};
```

**优先级**：内置类型 → 特殊前缀 → 插件遍历

## Dock 类模块化拆分

`Dock` 类已被拆分为多个辅助文件：

| 文件 | 职责 |
|------|------|
| `dock.init.ts` | 初始化相关 |
| `dock.layout.ts` | 布局相关 |
| `dock.button.ts` | 按钮生成 |
| `dock.toggle.ts` | 显示/隐藏切换 |
| `dock.visibility.ts` | 可见性判断 |
| `dock.size.ts` | 尺寸计算 |
| `dock.resize.ts` | 拖拽调整大小 |
| `dock.dnd.ts` | 拖放交互 |
| `dock.events.ts` | 事件处理 |
| `dock.model.ts` | Model 操作 |
| `dock.guard.ts` | 类型守卫 |
| `dock.environment.ts` | 环境访问 |

## Plugin 系统数据流

### Tab 相关

```
Plugin.addTab(options)
    ↓
this.models[name+type] = factory
    ↓
layout/util.ts: newModelByInitData()
    ↓
遍历 app.plugins 查找 models[type]
    ↓
Custom Model 实例化
```

### Dock 相关

```
Plugin.addDock(options)
    ↓
this.docks[name+type] = { config, model }
    ↓
loader.ts: afterLoadPlugin()
    ↓
Dock.genButton() 创建按钮
    ↓
Dock.toggleModel() 时调用 docks[type].model()
```

---

## Tab 系统重构方向

基于 Dock 系统的成熟模式，Tab 系统可以：

1. **创建 TabRegistry**：类似 `dock.registry.ts`，但用于 Tab 类型
2. **创建 TabFactory**：类似 `dock.factory.ts`，统一 Model 创建入口
3. **修改 Plugin.addTab**：委托给 TabRegistry
4. **修改 newModelByInitData**：优先查 TabRegistry
