# Vamana 并行构建技术方案

> 基于 DiskANN Rust 实现分析

## 1. 核心策略

DiskANN 使用 **分片并行 + 合并** 策略：

```
1. partition_data()     →  分片
2. build_shard_index()  →  每分片独立构建
3. merge_and_cleanup()  →  合并子图
```

## 2. 分片参数

| 参数 | DiskANN默认值 | Go建议值 |
|------|---------------|----------|
| 每分片向量数 | 500万 | **10万** (SiYuan轻量场景) |
| 每批处理数 | 1万 | 1万 |

## 3. 并行架构

### 3.1 单分片内并行

```go
func (idx *VamanaIndex) BuildParallel(vectors [][]float32, numWorkers int) error {
    idx.initializeForBuild(len(vectors))
    idx.precomputeNormSquares()
    
    order := rand.Perm(len(vectors))
    
    // 分块并行
    chunkSize := 10000
    for start := 0; start < len(order); start += chunkSize {
        end := min(start + chunkSize, len(order))
        idx.processChunkParallel(order[start:end], numWorkers)
    }
    return nil
}

func (idx *VamanaIndex) processChunkParallel(nodeIDs []int, numWorkers int) {
    var wg sync.WaitGroup
    ch := make(chan int, len(nodeIDs))
    
    for _, id := range nodeIDs {
        ch <- id
    }
    close(ch)
    
    for w := 0; w < numWorkers; w++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            scratch := idx.getScratch()
            defer idx.putScratch(scratch)
            
            for id := range ch {
                idx.buildNode(uint32(id), scratch)
            }
        }()
    }
    wg.Wait()
}
```

### 3.2 关键：节点级锁

DiskANN 用**细粒度锁**而非全局锁：

```go
type VamanaIndex struct {
    mu        sync.RWMutex     // 全局锁 (仅结构变更)
    nodeLocks []sync.RWMutex   // 每节点锁 (邻居更新)
}

func (idx *VamanaIndex) setNeighbors(id uint32, neighbors []uint32) {
    idx.nodeLocks[id].Lock()
    defer idx.nodeLocks[id].Unlock()
    idx.neighbors[id] = neighbors
}
```

## 4. 实现步骤

### P0: 基础并行
1. 添加 `BuildParallel` 方法
2. 每 worker 独立 `SearchScratch`
3. 节点级锁替代全局锁

### P1: 进度保存
1. 每 N 向量 checkpoint

### P2: 分片合并 (可选)
1. `partitionData` 数据分片
2. `mergeIndices` 索引合并
