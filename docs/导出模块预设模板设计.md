# Protyle 导出模块：文学编程动态模板系统设计

## 1. 背景与核心理念
为了彻底消除硬编码，我们将复用思源笔记成熟的 [文学编程 (Literate Programming)](file:///d:/dev/siyuan-note/docs/cronJob功能设计.md) 机制。用户直接在笔记中通过代码块定义模板逻辑，通过右键菜单将其“注册”为导出模板。

## 2. 笔记定义规范 (Literate Definition)

### 2.1 文档属性 (Attributes)
- `ext-lang`: `go` (后端执行) 或 `js` (如果未来支持前端预览渲染)。
- `ext-type`: `export-template` (标识此笔记为导出模板)。
- `export-format`: `pdf` | `html` | `md` (该模板支持的输出格式)。

### 2.2 代码块组织 (Code Blocks)
文档内的所有代码块将按顺序连接。
- **配置块**: 定义模板名称、作者、版本等元数据。
- **逻辑块**: 使用 Go 代码处理文档块树（Lute AST）。
- **静态资源块**: CSS 或 HTML 片段（可定义为变量）。

## 3. 零硬编码的工作流程

### 3.1 模板注册与发现
1. **右键注册**: 用户右键任意笔记 -> `注册为导出模板`。系统自动为该笔记打上属性。
2. **动态检索**: 导出对话框不再读取固定列表，而是执行 SQL 查询：
   `SELECT id, name FROM blocks WHERE type = 'd' AND [属性包含 ext-type=export-template]`。
3. **动态编译**: 当用户选择某模板时，内核实时提取其代码块并使用 Yaegi 编译。

### 3.2 导出执行 Pipeline
- **Input**: 目标文档 ID + 模板文档 ID。
- **Compiler**: 
    - 检索模板文档所有 `go` 代码块。
    - 拼合为扩展模块并注入 `siyuan.ExportContext`。
- **Execution (Yaegi)**:
    - 执行 `func Export(ctx *siyuan.ExportContext) error`。
    - `ExportContext` 提供 `GetRootBlock()` (获取 AST) 和 `WriteResult(data []byte)`。

## 4. 示例：笔记中的定义内容
```go
package main
import "siyuan"

// 模板名称会通过 Go 变量导出，不再硬编码在 TS
var TemplateName = "学术论文风 (V2)"

func Export(ctx *siyuan.ExportContext) error {
    root := ctx.GetRootBlock()
    // 动态遍历 AST，自动生成页眉页脚
    html := renderWithAcademicStyle(root)
    ctx.WriteResult([]byte(html))
    return nil
}
```
