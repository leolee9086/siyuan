# 过滤操作性能优化计划

## 1. 问题定位

### 1.1 核心问题概述

[`Filter()`](../../kernel/av/filter.go) 函数是数据视图过滤的核心实现，存在严重的性能瓶颈。当数据量超过1000条且过滤条件超过3个时，响应时间会超过500ms，严重影响用户体验。

**文件位置**: [`kernel/av/filter.go`](../../kernel/av/filter.go)

### 1.2 具体性能问题

#### 1.2.1 嵌套循环导致高时间复杂度

**问题描述**: [`Filter()`](../../kernel/av/filter.go) 函数使用嵌套循环处理过滤逻辑，时间复杂度为 O(n×m)，其中：
- n = 数据项数量
- m = 过滤条件数量

**代码位置**: [`kernel/av/filter.go`](../../kernel/av/filter.go) 主循环

```go
// 伪代码示例
for each item in items {
    for each filter in filters {
        // 过滤逻辑
    }
}
```

**性能影响**:
- 100条数据 × 3个条件 = 300次迭代
- 1000条数据 × 5个条件 = 5000次迭代
- 5000条数据 × 10个条件 = 50000次迭代

#### 1.2.2 字段索引查找效率低

**问题描述**: 每个过滤条件都需要遍历所有字段来查找匹配的列索引。

**代码位置**: [`kernel/av/filter.go:98-105`](../../kernel/av/filter.go:98)

```go
for _, col := range view.Table.Columns {
    if col.ID == filter.Column {
        // 找到匹配列
    }
}
```

**性能影响**:
- 对于包含20+列的视图，每次过滤都需要进行大量的字符串比较
- 1000条数据 × 5个过滤条件 × 20列查找 = 100000次字符串比较
- 时间复杂度: O(n×m×k)，k为列数

#### 1.2.3 汇总字段过滤性能差

**问题描述**: 汇总字段过滤时需要动态构建内容，涉及多次数据遍历和聚合计算。

**代码位置**: [`kernel/av/filter.go:192`](../../kernel/av/filter.go:192) 调用 [`BuildContents`](../../kernel/av/value.go:843)

**涉及操作**:
1. 查询关联的数据库记录
2. 执行聚合计算（Sum、Average、Count等）
3. 多次数据遍历

**性能影响**:
- 每个汇总字段过滤响应时间增加3-5倍
- 100条数据的汇总字段过滤: ~150-250ms
- 1000条数据的汇总字段过滤: ~1.5-2.5s

#### 1.2.4 关联字段过滤开销大

**问题描述**: 关联字段过滤需要遍历所有关联值进行匹配检查。

**代码位置**: [`kernel/av/filter.go:336-354`](../../kernel/av/filter.go:336)

```go
for _, relation := range relationValues {
    // 检查每个关联值是否匹配过滤条件
}
```

**性能影响**:
- 如果每条记录平均有5个关联值
- 1000条数据 × 5个关联值 = 5000次额外遍历
- 响应时间增加2-3倍

#### 1.2.5 资源字段过滤效率低

**问题描述**: 资源字段过滤需要遍历所有资源项进行匹配。

**代码位置**: [`kernel/av/filter.go:408-420`](../../kernel/av/filter.go:408)

```go
for _, asset := range assetValues {
    // 检查每个资源是否匹配过滤条件
}
```

**性能影响**:
- 如果每条记录平均有3个资源
- 1000条数据 × 3个资源 = 3000次额外遍历
- 响应时间增加1.5-2倍

#### 1.2.6 文本过滤算法简单

**问题描述**: 使用 `strings.Contains` 等基础函数进行文本匹配，对大量数据性能较差。

**代码位置**: [`kernel/av/filter.go`](../../kernel/av/filter.go) 文本过滤逻辑

**性能影响**:
- 简单字符串匹配对短文本性能尚可
- 对长文本（>1000字符）性能下降明显
- 缺少优化的模式匹配算法

### 1.3 性能影响量化

| 数据量 | 过滤条件数 | 预估响应时间 | 用户体验 |
|--------|-----------|-------------|---------|
| 100条 | 1-2个 | < 50ms | 良好 |
| 500条 | 3-5个 | 200-500ms | 可接受 |
| 1000条 | 3-5个 | 500ms-1s | 明显延迟 |
| 5000条 | 5+个 | 2-5s | 严重影响 |

**特别影响**:
- 汇总字段过滤：响应时间增加 3-5倍
- 关联字段过滤：响应时间增加 2-3倍
- 多条件组合过滤：性能呈指数级下降

```go
package av

import (

// 生成测试数据
func generateBenchmarkData(rowCount, columnCount int) *AttributeView {
    av := &AttributeView{
        ID:   "bench_av_" + fmt.Sprintf("%d", time.Now().Unix()),
        Name: "Benchmark Test View",
    }
    
    // 创建列定义
    columns := make([]*Column, columnCount)
    for i := 0; i < columnCount; i++ {
        colType := []string{"text", "number", "date", "select", "relation", "rollup"}[i%6]
        columns[i] = &Column{
            ID:   fmt.Sprintf("col_%d", i),
            Name: fmt.Sprintf("Column %d", i),
            Type: colType,
        }
    }
    
    // 创建行数据
    rows := make([]*Row, rowCount)
    for i := 0; i < rowCount; i++ {
        row := &Row{
            ID:     fmt.Sprintf("row_%d", i),
            Values: make([]*Value, columnCount),
        }
        
        for j := 0; j < columnCount; j++ {
            row.Values[j] = generateValueByType(columns[j].Type, i, j)
        }
        
        rows[i] = row
    }
    
    av.Views = []*View{{
        ID:   "view_1",
        Name: "Default View",
        Table: &Table{
            Columns: columns,
            Rows:    rows,
        },
    }}
    
    return av
}

// 根据类型生成值
func generateValueByType(colType string, rowIdx, colIdx int) *Value {
    value := &Value{
        ID:   fmt.Sprintf("val_%d_%d", rowIdx, colIdx),
        Type: colType,
    }
    
    switch colType {
    case "text":
        value.Text = &TextValue{
            Content: fmt.Sprintf("Text content %d-%d", rowIdx, colIdx),
        }
    case "number":
        value.Number = &NumberValue{
            Content: float64(rand.Intn(10000)),
        }
    case "date":
        value.Date = &DateValue{
            Content: time.Now().Add(time.Duration(rowIdx) * time.Hour).Unix(),
        }
    case "select":
        options := []string{"Option A", "Option B", "Option C", "Option D"}
        value.Select = &SelectValue{
            Content: options[rowIdx%len(options)],
        }
    case "relation":
        // 生成3-5个关联值
        relationCount := 3 + rand.Intn(3)
        relations := make([]*RelationValue, relationCount)
        for i := 0; i < relationCount; i++ {
            relations[i] = &RelationValue{
                ID: fmt.Sprintf("rel_%d_%d_%d", rowIdx, colIdx, i),
            }
        }
        value.Relation = &RelationValues{Contents: relations}
    case "rollup":
        // 汇总字段，需要关联数据
        value.Rollup = &RollupValue{
            RelationID: fmt.Sprintf("rel_col_%d", colIdx),
            CalcType:   []string{"count", "sum", "average"}[rand.Intn(3)],
        }
    }
    
    return value
}

// 生成过滤条件
func generateFilters(columnCount, filterCount int) []*Filter {
    filters := make([]*Filter, filterCount)
    
    for i := 0; i < filterCount; i++ {
        colIdx := i % columnCount
        colType := []string{"text", "number", "date", "select", "relation", "rollup"}[colIdx%6]
        
        filters[i] = &Filter{
            Column:   fmt.Sprintf("col_%d", colIdx),
            Operator: getOperatorByType(colType),
            Value:    getFilterValueByType(colType, i),
        }
    }
    
    return filters
}

func getOperatorByType(colType string) string {
    operators := map[string][]string{
        "text":     {"contains", "not_contains", "is", "is_not"},
        "number":   {"=", ">", "<", ">=", "<="},
        "date":     {"is", "before", "after"},
        "select":   {"is", "is_not"},
        "relation": {"contains", "not_contains"},
        "rollup":   {"=", ">", "<"},
    }
    ops := operators[colType]
    return ops[rand.Intn(len(ops))]
}

func getFilterValueByType(colType string, idx int) interface{} {
    switch colType {
    case "text":
        return fmt.Sprintf("Text content %d", idx)
    case "number":
        return float64(5000 + idx*100)
    case "date":
        return time.Now().Add(time.Duration(idx) * 24 * time.Hour).Unix()
    case "select":
        return "Option B"
    case "relation":
        return fmt.Sprintf("rel_%d", idx)
    case "rollup":
        return float64(100 + idx*10)
    default:
        return nil
    }
}
```

### 2.6 问题暴露验证

#### 2.6.1 验证标准

为了证明性能问题确实存在，需要满足以下条件：

**条件1：嵌套循环问题**
- 当数据量从100增加到1000时（10倍），响应时间应增加10倍以上
- 当过滤条件从1增加到10时（10倍），响应时间应增加接近10倍

**条件2：字段索引查找问题**
- 当列数从10增加到100时（10倍），响应时间应增加明显（>30%）

**条件3：汇总字段问题**
- 包含汇总字段的过滤应比普通字段慢3-5倍

**条件4：关联字段问题**
- 包含关联字段的过滤应比普通字段慢2-3倍

#### 2.6.2 验证测试代码

```go
// 位置: kernel/av/filter_bench_test.go

// TestFilterPerformanceRegression 验证性能问题存在
func TestFilterPerformanceRegression(t *testing.T) {
    // 测试1：验证O(n×m)复杂度
    t.Run("VerifyComplexity", func(t *testing.T) {
        // 100条数据，3个过滤条件
        av100 := generateBenchmarkData(100, 20)
        filters3 := generateFilters(20, 3)
        
        start := time.Now()
        Filter(av100.Views[0], filters3)
        time100_3 := time.Since(start)
        
        // 1000条数据，3个过滤条件
        av1000 := generateBenchmarkData(1000, 20)
        
        start = time.Now()
        Filter(av1000.Views[0], filters3)
        time1000_3 := time.Since(start)
        
        // 验证：1000条应该比100条慢约10倍
        ratio := float64(time1000_3) / float64(time100_3)
        if ratio < 8.0 {
            t.Errorf("数据量增加10倍，但响应时间仅增加%.2f倍，未能暴露O(n)问题", ratio)
        }
        
        t.Logf("100条数据: %v", time100_3)
        t.Logf("1000条数据: %v", time1000_3)
        t.Logf("性能比率: %.2fx", ratio)
        
        // 1000条数据，10个过滤条件
        filters10 := generateFilters(20, 10)
        
        start = time.Now()
        Filter(av1000.Views[0], filters10)
        time1000_10 := time.Since(start)
        
        // 验证：10个条件应该比3个条件慢约3倍
        filterRatio := float64(time1000_10) / float64(time1000_3)
        if filterRatio < 2.5 {
            t.Errorf("过滤条件增加3.3倍，但响应时间仅增加%.2f倍，未能暴露O(m)问题", filterRatio)
        }
        
        t.Logf("3个过滤条件: %v", time1000_3)
        t.Logf("10个过滤条件: %v", time1000_10)
        t.Logf("过滤条件比率: %.2fx", filterRatio)
    })
    
    // 测试2：验证字段索引查找问题
    t.Run("VerifyColumnLookup", func(t *testing.T) {
        rowCount := 1000
        filterCount := 5
        
        // 10列
        av10 := generateBenchmarkData(rowCount, 10)
        filters10 := generateFilters(10, filterCount)
        
        start := time.Now()
        Filter(av10.Views[0], filters10)
        time10cols := time.Since(start)
        
        // 100列
        av100 := generateBenchmarkData(rowCount, 100)
        filters100 := generateFilters(100, filterCount)
        
        start = time.Now()
        Filter(av100.Views[0], filters100)
        time100cols := time.Since(start)
        
        // 验证：100列应该比10列慢30%以上
        ratio := float64(time100cols) / float64(time10cols)
        if ratio < 1.3 {
            t.Errorf("列数增加10倍，但响应时间仅增加%.2f倍，未能暴露列查找问题", ratio)
        }
        
        t.Logf("10列: %v", time10cols)
        t.Logf("100列: %v", time100cols)
        t.Logf("性能比率: %.2fx", ratio)
    })
    
    // 测试3：验证汇总字段性能问题
    t.Run("VerifyRollupPerformance", func(t *testing.T) {
        rowCount := 500
        
        // 普通文本字段过滤
        avText := generateBenchmarkData(rowCount, 20)
        filterText := &Filter{
            Column:   "col_0", // text类型
            Operator: "contains",
            Value:    "Text content",
        }
        
        start := time.Now()
        Filter(avText.Views[0], []*Filter{filterText})
        timeText := time.Since(start)
        
        // 汇总字段过滤
        filterRollup := &Filter{
            Column:   "col_5", // rollup类型
            Operator: ">",
            Value:    100.0,
        }
        
        start = time.Now()
        Filter(avText.Views[0], []*Filter{filterRollup})
        timeRollup := time.Since(start)
        
        // 验证：汇总字段应该比文本字段慢3倍以上
        ratio := float64(timeRollup) / float64(timeText)
        if ratio < 3.0 {
            t.Errorf("汇总字段过滤仅比文本字段慢%.2f倍，未达到预期的3倍以上", ratio)
        }
        
        t.Logf("文本字段过滤: %v", timeText)
        t.Logf("汇总字段过滤: %v", timeRollup)
        t.Logf("性能比率: %.2fx", ratio)
    })
}
```

#### 2.8.2 问题暴露标准

测试必须满足以下条件才能证明问题存在：

1. **1000条数据 + 5个过滤条件的响应时间 > 500ms**
   - 如果 < 500ms，说明当前性能可接受，不需要优化
   
2. **数据量线性增长导致响应时间线性增长**
   - 100条→1000条（10倍）：响应时间应增加8-12倍
   
3. **过滤条件增加导致响应时间线性增长**
   - 3个条件→10个条件（3.3倍）：响应时间应增加2.5-4倍
   
4. **列数增加导致响应时间增加**
   - 10列→100列（10倍）：响应时间应增加30%以上
   
5. **汇总字段过滤明显慢于普通字段**
   - 汇总字段响应时间应为普通字段的3-5倍

### 3.1 优化方案概述

### 3.2 P0优化方案（立即实施）

#### 3.2.1 建立字段索引映射

**目标**: 消除字段查找的O(k)复杂度，将其降低到O(1)

**实现位置**: [`kernel/av/filter.go`](../../kernel/av/filter.go)

**实现代码**:

```go
// 位置: kernel/av/filter.go

// ColumnIndexMap 列索引映射缓存
type ColumnIndexMap struct {
    indexMap map[string]int
    columns  []*Column
    version  int64 // 用于检测列定义是否变化
}

// buildColumnIndexMap 构建列索引映射
func buildColumnIndexMap(columns []*Column) *ColumnIndexMap {
    indexMap := make(map[string]int, len(columns))
    for i, col := range columns {
        indexMap[col.ID] = i
    }
    
    return &ColumnIndexMap{
        indexMap: indexMap,
        columns:  columns,
        version:  time.Now().UnixNano(),
    }
}

// getColumnIndex 快速获取列索引
func (cim *ColumnIndexMap) getColumnIndex(columnID string) int {
    if idx, ok := cim.indexMap[columnID]; ok {
        return idx
    }
    return -1
}

// Filter 优化后的过滤函数
func Filter(view *View, filters []*Filter) []*Row {
    if len(filters) == 0 {
        return view.Table.Rows
    }
    
    // 构建列索引映射（只需一次）
    colIndexMap := buildColumnIndexMap(view.Table.Columns)
    
    result := make([]*Row, 0, len(view.Table.Rows))
    
    for _, row := range view.Table.Rows {
        if matchAllFilters(row, filters, colIndexMap) {
            result = append(result, row)
        }
    }
    
    return result
}

// matchAllFilters 检查行是否匹配所有过滤条件
func matchAllFilters(row *Row, filters []*Filter, colIndexMap *ColumnIndexMap) bool {
    for _, filter := range filters {
        // O(1)查找列索引
        colIdx := colIndexMap.getColumnIndex(filter.Column)
        if colIdx < 0 || colIdx >= len(row.Values) {
            return false
        }
        
        value := row.Values[colIdx]
        if !matchFilter(value, filter) {
            return false
        }
    }
    return true
}
```

**预期收益**:
- 减少60-80%的字段查找时间
- 1000条数据×5个过滤条件：从~800ms降低到~400ms

#### 3.2.2 缓存汇总字段结果

**目标**: 避免重复计算汇总字段值

**实现位置**: [`kernel/av/value.go`](../../kernel/av/value.go)

**实现代码**:

```go
// 位置: kernel/av/value.go

// RollupCache 汇总字段缓存
type RollupCache struct {
    mu        sync.RWMutex
    cache     map[string]*RollupCacheEntry
    maxSize   int
    evictList *list.List // LRU淘汰列表
}

type RollupCacheEntry struct {
    value      interface{}
    dataHash   string
    timestamp  time.Time
    accessTime time.Time
}

var globalRollupCache = &RollupCache{
    cache:     make(map[string]*RollupCacheEntry),
    maxSize:   1000,
    evictList: list.New(),
}

// computeRollupHash 计算汇总字段的数据指纹
func (v *RollupValue) computeRollupHash() string {
    h := sha256.New()
    h.Write([]byte(v.RelationID))
    h.Write([]byte(v.CalcType))
    for _, id := range v.RecordIDs {
        h.Write([]byte(id))
    }
    return hex.EncodeToString(h.Sum(nil))
}

// BuildContents 优化后的汇总字段构建
func (v *RollupValue) BuildContents() {
    cacheKey := fmt.Sprintf("%s_%s", v.RelationID, v.CalcType)
    dataHash := v.computeRollupHash()
    
    // 尝试从缓存获取
    globalRollupCache.mu.RLock()
    if entry, ok := globalRollupCache.cache[cacheKey]; ok {
        if entry.dataHash == dataHash && time.Since(entry.timestamp) < 5*time.Minute {
            v.Contents = entry.value
            entry.accessTime = time.Now()
            globalRollupCache.mu.RUnlock()
            return
        }
    }
    globalRollupCache.mu.RUnlock()
    
    // 缓存未命中，执行计算
    contents := v.calcContents()
    
    // 更新缓存
    globalRollupCache.mu.Lock()
    globalRollupCache.cache[cacheKey] = &RollupCacheEntry{
        value:      contents,
        dataHash:   dataHash,
        timestamp:  time.Now(),
        accessTime: time.Now(),
    }
    
    // LRU淘汰
    if len(globalRollupCache.cache) > globalRollupCache.maxSize {
        globalRollupCache.evictOldest()
    }
    globalRollupCache.mu.Unlock()
    
    v.Contents = contents
}

// evictOldest 淘汰最久未使用的缓存项
func (rc *RollupCache) evictOldest() {
    var oldestKey string
    var oldestTime time.Time = time.Now()
    
    for key, entry := range rc.cache {
        if entry.accessTime.Before(oldestTime) {
            oldestTime = entry.accessTime
            oldestKey = key
        }
    }
    
    if oldestKey != "" {
        delete(rc.cache, oldestKey)
    }
}
```
