## 1. 问题定位

### 1.1 核心问题概述

[`Value`](../../kernel/av/value.go) 结构体是数据视图中最基础的数据单元,所有数据操作都涉及值对象的处理。当前实现存在严重的性能问题,特别是在大量值对象操作时,克隆、字符串转换、空值判断等操作的累积影响显著。

**文件位置**: [`kernel/av/value.go`](../../kernel/av/value.go)

### 1.2 具体性能问题

#### 1.2.1 Clone方法使用JSON序列化

**问题描述**: [`Clone()`](../../kernel/av/value.go:196) 方法使用JSON序列化/反序列化实现深拷贝。

**代码位置**: [`kernel/av/value.go:196-204`](../../kernel/av/value.go:196)

```go
func (value *Value) Clone() (ret *Value) {
	data, err := gulu.JSON.MarshalJSON(value)
	if err != nil {
		return
	}
	err = gulu.JSON.UnmarshalJSON(data, &ret)
	if err != nil {
		return
	}
	return
}
```

**性能影响**:
- JSON序列化/反序列化性能开销大
- 涉及反射操作,CPU密集
- 产生大量临时内存分配
- 对于简单值类型完全没必要
- 克隆1000个简单值: ~50ms (JSON) vs ~5ms (直接复制)
- 克隆1000个复杂值: ~200ms (JSON) vs ~20ms (结构化复制)

#### 1.2.2 String方法复杂度高

**问题描述**: [`String()`](../../kernel/av/value.go:73) 方法包含大量类型判断和字符串拼接。

**代码位置**: [`kernel/av/value.go:73-185`](../../kernel/av/value.go:73)

```go
func (value *Value) String(format bool) string {
	if nil == value {
		return ""
	}

	switch value.Type {
	case KeyTypeBlock:
		if nil == value.Block {
			return ""
		}
		return strings.TrimSpace(value.Block.Content)
	case KeyTypeText:
		if nil == value.Text {
			return ""
		}
		return strings.TrimSpace(value.Text.Content)
	case KeyTypeNumber:
		if nil == value.Number {
			return ""
		}
		if format {
			return value.Number.FormattedContent
		}
		return fmt.Sprintf("%f", value.Number.Content)
	// ... 20+ 个 case 分支
	}
}
```

**性能影响**:
- 每次调用都需要完整的类型判断
- 复杂类型(如汇总、关联)需要递归处理
- 频繁的字符串拼接和格式化
- 没有结果缓存
- 1000次字符串转换: ~30ms

#### 1.2.3 IsEmpty和IsBlank重复逻辑

**问题描述**: [`IsEmpty()`](../../kernel/av/value.go:228) 和 [`IsBlank()`](../../kernel/av/value.go:306) 方法存在大量重复代码。

**代码位置**: [`kernel/av/value.go:228-304`](../../kernel/av/value.go:228), [`kernel/av/value.go:306-382`](../../kernel/av/value.go:306)

```go
func (value *Value) IsEmpty() bool {
	switch value.Type {
	case KeyTypeText:
		return value.Text == nil || value.Text.Content == ""
	case KeyTypeNumber:
		return value.Number == nil
	// ... 重复的类型判断
	}
}

func (value *Value) IsBlank() bool {
	switch value.Type {
	case KeyTypeText:
		if nil == value.Text {
			return true
		}
		return "" == strings.TrimSpace(value.Text.Content)
	case KeyTypeNumber:
		if nil == value.Number {
			return true
		}
		return !value.Number.IsNotEmpty
	// ... 几乎相同的类型判断
	}
}
```

**性能影响**:
- 代码重复率高达80%
- 维护困难,容易不一致
- 两个方法经常被连续调用,浪费性能
- 10000次空值判断: ~20ms

#### 1.2.4 数字格式化效率低

**问题描述**: 数字格式化每次都创建新的Printer实例。

**代码位置**: [`kernel/av/value.go:545-607`](../../kernel/av/value.go:545)

```go
func formatNumber(num float64, format NumberFormat) string {
	printer := message.NewPrinter(language.Tag(format.Locale))
	// 每次都创建新的 Printer 实例
	return printer.Sprintf(format.Pattern, num)
}
```

**性能影响**:
- 每次格式化都创建新实例
- Printer初始化有性能开销
- 应该复用Printer实例
- 1000次数字格式化: ~40ms

### 1.3 性能影响量化

| 操作类型 | 数据量 | 当前性能 | 影响程度 |
|---------|--------|---------|---------|
| 值克隆 | 1000个 | ~50ms | 中等 |
| 字符串转换 | 1000次 | ~30ms | 中等 |
| 空值判断 | 10000次 | ~20ms | 低 |
| 数字格式化 | 1000次 | ~40ms | 中等 |

**特别影响**:
- 在过滤、排序、计算中被频繁调用,放大性能问题
- 大量值对象操作时,累积影响显著
- 克隆操作在数据复制场景下成为瓶颈

## 2. 定量Benchmark方案

### 2.1 Benchmark设计原则

#### 2.1.1 真实场景模拟

**核心原则**: 所有benchmark必须基于真实业务场景,而非孤立的单元测试。

**场景分类**:
1. **高频操作场景**: 克隆、字符串转换、空值判断
2. **批量操作场景**: 大量值对象的批处理
3. **复杂类型场景**: 关联、汇总等复杂值类型
4. **混合场景**: 多种操作组合的真实工作流

#### 2.1.2 数据规模设计

**规模梯度**:
- **小规模**: 100个值对象 (单次操作)
- **中规模**: 1,000个值对象 (常规视图)
- **大规模**: 10,000个值对象 (大型数据库)
- **超大规模**: 100,000个值对象 (压力测试)

**类型分布**:
- 简单类型(Text/Number): 60%
- 中等复杂度(Date/Select): 30%
- 复杂类型(Relation/Rollup): 10%

```go
	for i := range rows {
		cells := make([]*Cell, 5)

					Number: &ValueNumber{Content: rand.Float64() * 1000},

		// 计算每列的总和、平均值、最大值、最小值
		for colIdx := 0; colIdx < 5; colIdx++ {
			var sum, max, min float64
			count := 0
			first := true
			
			for _, row := range rows {
				val := row.Cells[colIdx].Value
				if val.IsEmpty() {
					continue
				}
				
				str := val.String(false)
				num := parseFloat(str)
				
				sum += num
				count++
				
				if first {
					max = num
					min = num
					first = false
				} else {
					if num > max {
						max = num
					}
					if num < min {
						min = num
					}
				}
			}
			
			_ = sum / float64(count) // 平均值
		}
	}
}
```

**确保优化不引入错误**:

```go
// TestValueClone_Correctness 验证克隆的正确性
func TestValueClone_Correctness(t *testing.T) {
	testCases := []struct {
		name  string
		value *Value
	}{
		{"Text", &Value{Type: KeyTypeText, Text: &ValueText{Content: "测试"}}},
		{"Number", &Value{Type: KeyTypeNumber, Number: &ValueNumber{Content: 123.456}}},
		{"Relation", &Value{Type: KeyTypeRelation, Relation: &ValueRelation{
			Contents: []*Value{
				{Type: KeyTypeText, Text: &ValueText{Content: "关联1"}},
			},
		}}},
		// ... 更多测试用例
	}
	
	for _, tc := range testCases {
		t.Run(tc.name, func(t *testing.T) {
			cloned := tc.value.Clone()
			
			// 验证深拷贝
			if cloned == tc.value {
				t.Error("Clone should create a new instance")
			}
			
			// 验证内容相等
			if !reflect.DeepEqual(cloned, tc.value) {
				t.Error("Cloned value should be equal to original")
			}
			
			// 验证修改不影响原值
			modifyValue(cloned)
			if reflect.DeepEqual(cloned, tc.value) {
				t.Error("Modifying cloned value should not affect original")
			}
		})
	}
}
```
