# 排序操作性能优化计划

## 1. 问题定位

### 1.1 核心问题概述

[`Sort()`](../../kernel/av/sort.go) 函数是数据视图排序的核心实现，存在严重的性能瓶颈。当数据量超过1000条且排序字段超过3个时，特别是涉及中文拼音排序时，响应时间会超过1秒，严重影响用户体验。

**文件位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

### 1.2 具体性能问题

#### 1.2.1 编辑状态判断开销

**问题描述**: [`Sort()`](../../kernel/av/sort.go) 函数需要先遍历所有项目判断是否编辑过，每次排序都需要完整遍历一次数据。

**代码位置**: [`kernel/av/sort.go:64-82`](../../kernel/av/sort.go:64)

```go
for _, item := range items {
    if isItemEdited(item) {
        editedItems = append(editedItems, item)
    } else {
        uneditedItems = append(uneditedItems, item)
    }
}
```

**性能影响**:
- 1000条数据需要遍历1000次判断编辑状态
- 即使编辑状态未改变，每次排序都要重新判断
- 时间复杂度: O(n)，n为数据项数量
- 对于频繁排序操作，这个开销会累积

#### 1.2.2 双重排序开销

**问题描述**: 对已编辑和未编辑项目分别排序，增加了额外的遍历和比较操作。

**代码位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go) 排序逻辑

```go
sort.Slice(editedItems, compareFunc)
sort.Slice(uneditedItems, compareFunc)
result = append(editedItems, uneditedItems...)
```

**性能影响**:
- 排序时间增加约30-50%
- 两次排序操作：O(n₁ log n₁) + O(n₂ log n₂)，其中n₁+n₂=n
- 最坏情况下（所有项目都编辑或都未编辑），仍需要完整排序
- 内存分配增加：需要创建两个临时切片

#### 1.2.3 多字段排序复杂度高

**问题描述**: 多字段排序时，每次比较都需要遍历所有排序字段。

**代码位置**: [`kernel/av/sort.go:108-134`](../../kernel/av/sort.go:108)

```go
for _, sortField := range sortFields {
    result := compareByField(item1, item2, sortField)
    if result != 0 {
        return result
    }
}
```

**性能影响**:
- 时间复杂度: O(n log n × k)，k为排序字段数量
- 1000条数据 × 3个排序字段：约10000次字段比较
- 每增加一个排序字段，比较次数线性增加
- 对于5个排序字段，性能下降约50%

#### 1.2.4 拼音排序性能开销

**问题描述**: 字符串比较使用 [`util.PinYinCompare`](../../kernel/av/sort.go:165)，性能开销大。

**代码位置**: [`kernel/av/sort.go:165`](../../kernel/av/sort.go:165)

```go
// 拼音排序需要：
// 1. 将中文转换为拼音
// 2. 进行字符串比较
result := util.PinYinCompare(str1, str2)
```

**性能影响**:
- 中文排序比英文排序慢5-10倍
- 每次比较都需要转换拼音，无缓存机制
- 1000条中文数据排序：约10000次拼音转换
- 拼音转换涉及Unicode处理和查表操作，CPU密集

#### 1.2.5 选择字段排序查找开销

**问题描述**: 选择字段排序需要查找选项顺序，每次比较都需要线性查找。

**代码位置**: [`kernel/av/sort.go:267-273`](../../kernel/av/sort.go:267)

```go
for i, option := range selectOptions {
    if option.ID == selectedValue {
        return i // 返回选项位置
    }
}
```

**性能影响**:
- 每次比较都需要线性查找，O(m)复杂度，m为选项数量
- 如果有20个选项，每次比较平均需要10次查找
- 1000条数据排序：约100000次选项查找
- 时间复杂度: O(n log n × m)

#### 1.2.6 关联和汇总字段排序开销

**问题描述**: 需要拼接多个值的字符串，涉及大量字符串操作和内存分配。

**代码位置**: [`kernel/av/sort.go:414-434`](../../kernel/av/sort.go:414)

```go
var values []string
for _, relation := range relations {
    values = append(values, relation.String())
}
sortKey := strings.Join(values, ",")
```

**性能影响**:
- 大量字符串拼接和内存分配
- 每个关联字段平均5个关联值
- 1000条数据 × 5个关联值 = 5000次字符串拼接
- 汇总字段还需要额外的聚合计算
- 响应时间增加3-5倍

### 1.3 性能影响量化

| 数据量 | 排序字段 | 字段类型 | 预估响应时间 | 用户体验 |
|--------|---------|---------|-------------|---------|
| 100条 | 1个 | 文本 | < 20ms | 优秀 |
| 500条 | 2个 | 文本 | 100-200ms | 良好 |
| 1000条 | 3个 | 中文文本 | 500ms-1s | 可接受 |
| 5000条 | 3+个 | 中文/汇总 | 3-8s | 严重影响 |

**特别影响**:
- 中文拼音排序：比英文排序慢5-10倍
- 汇总字段排序：比普通字段慢3-5倍
- 多字段排序：每增加一个字段，时间增加20-30%
- 选择字段排序：选项越多，性能越差

```go
// 生成排序测试数据
func generateSortBenchmarkData(rowCount, columnCount int, editedRatio float64) *AttributeView {
    av := &AttributeView{
        ID:   "bench_sort_av_" + fmt.Sprintf("%d", time.Now().Unix()),
        Name: "Sort Benchmark Test View",
    }
    
    // 创建列定义
    columns := make([]*Column, columnCount)
    columnTypes := []string{"text", "number", "date", "select", "relation", "rollup"}
    
    for i := 0; i < columnCount; i++ {
        colType := columnTypes[i%len(columnTypes)]
        columns[i] = &Column{
            ID:   fmt.Sprintf("col_%d", i),
            Name: fmt.Sprintf("Column %d", i),
            Type: colType,
        }
        
        // 为选择字段添加选项
        if colType == "select" {
            columns[i].Options = generateSelectOptions(20)
        }
    }
    
    // 创建行数据
    rows := make([]*Row, rowCount)
    editedCount := int(float64(rowCount) * editedRatio)
    
    for i := 0; i < rowCount; i++ {
        row := &Row{
            ID:      fmt.Sprintf("row_%d", i),
            Values:  make([]*Value, columnCount),
            IsEdited: i < editedCount, // 前N条标记为已编辑
        }
        
        for j := 0; j < columnCount; j++ {
            row.Values[j] = generateSortValueByType(columns[j].Type, i, j, columns[j].Options)
        }
        
        rows[i] = row
    }
    
    av.Views = []*View{{
        ID:   "view_1",
        Name: "Default View",
        Table: &Table{
            Columns: columns,
            Rows:    rows,
        },
    }}
    
    return av
}

// 生成选择字段选项
func generateSelectOptions(count int) []*SelectOption {
    options := make([]*SelectOption, count)
    for i := 0; i < count; i++ {
        options[i] = &SelectOption{
            ID:    fmt.Sprintf("opt_%d", i),
            Name:  fmt.Sprintf("Option %d", i),
            Color: fmt.Sprintf("#%06x", rand.Intn(0xFFFFFF)),
        }
    }
    return options
}

// 根据类型生成排序值
func generateSortValueByType(colType string, rowIdx, colIdx int, options []*SelectOption) *Value {
    value := &Value{
        ID:   fmt.Sprintf("val_%d_%d", rowIdx, colIdx),
        Type: colType,
    }
    
    switch colType {
    case "text":
        // 生成中文和英文混合文本
        if rowIdx%2 == 0 {
            value.Text = &TextValue{
                Content: generateChineseText(rowIdx, colIdx),
            }
        } else {
            value.Text = &TextValue{
                Content: fmt.Sprintf("Text %d-%d", rowIdx, colIdx),
            }
        }
        
    case "number":
        value.Number = &NumberValue{
            Content: float64(rand.Intn(10000)),
        }
        
    case "date":
        value.Date = &DateValue{
            Content: time.Now().Add(time.Duration(rowIdx) * time.Hour).Unix(),
        }
        
    case "select":
        if len(options) > 0 {
            value.Select = &SelectValue{
                Content: options[rowIdx%len(options)].ID,
            }
        }
        
    case "relation":
        // 生成3-5个关联值
        relationCount := 3 + rand.Intn(3)
        relations := make([]*RelationValue, relationCount)
        for i := 0; i < relationCount; i++ {
            relations[i] = &RelationValue{
                ID:   fmt.Sprintf("rel_%d_%d_%d", rowIdx, colIdx, i),
                Name: fmt.Sprintf("Relation %d", i),
            }
        }
        value.Relation = &RelationValues{Contents: relations}
        
    case "rollup":
        // 汇总字段
        value.Rollup = &RollupValue{
            RelationID: fmt.Sprintf("rel_col_%d", colIdx),
            CalcType:   []string{"count", "sum", "average"}[rand.Intn(3)],
            Contents:   float64(rand.Intn(1000)),
        }
    }
    
    return value
}

// 生成中文文本（用于测试拼音排序）
func generateChineseText(rowIdx, colIdx int) string {
    chineseChars := []string{
        "阿", "波", "次", "的", "额", "佛", "哥", "喝", "一", "就",
        "科", "了", "么", "呢", "哦", "破", "去", "日", "思", "特",
        "乌", "无", "西", "呀", "在", "张", "李", "王", "赵", "钱",
    }
    
    // 生成3-5个中文字符
    length := 3 + rand.Intn(3)
    result := ""
    for i := 0; i < length; i++ {
        result += chineseChars[(rowIdx+colIdx+i)%len(chineseChars)]
    }
    return result
}

// 生成排序配置
func generateSortConfig(columnCount, sortFieldCount int) []*SortField {
    sortFields := make([]*SortField, sortFieldCount)
    
    for i := 0; i < sortFieldCount; i++ {
        colIdx := i % columnCount
        sortFields[i] = &SortField{
            ColumnID:  fmt.Sprintf("col_%d", colIdx),
            Direction: []string{"asc", "desc"}[i%2],
        }
    }
    
    return sortFields
}
```

### 2.6 问题暴露验证

#### 2.6.1 验证标准

为了证明性能问题确实存在，需要满足以下条件：

**条件1：编辑状态判断开销**
- 编辑状态比例从0%到100%，响应时间应有明显差异（>20%）
- 验证每次排序都需要遍历判断编辑状态

**条件2：双重排序开销**
- 双重排序应比单次排序慢30-50%
- 50%编辑状态时性能最差（两个子集大小相近）

**条件3：多字段排序复杂度**
- 排序字段从1个增加到5个，响应时间应线性增长
- 5个字段应比1个字段慢4-5倍

**条件4：中文拼音排序瓶颈**
- 中文排序应比英文排序慢5-10倍
- 1000条中文数据排序响应时间应>500ms

**条件5：选择字段查找开销**
- 选项数量从10增加到100，响应时间应增加明显（>50%）

**条件6：关联和汇总字段开销**
- 关联字段排序应比普通字段慢2-3倍
- 汇总字段排序应比普通字段慢3-5倍

#### 2.6.2 验证测试代码

```go
// 位置: kernel/av/sort_bench_test.go

// TestSortPerformanceRegression 验证性能问题存在
func TestSortPerformanceRegression(t *testing.T) {
    // 测试1：验证编辑状态判断开销
    t.Run("VerifyEditedStateOverhead", func(t *testing.T) {
        rowCount := 1000
        sortFieldCount := 3
        
        // 0%编辑
        av0 := generateSortBenchmarkData(rowCount, 20, 0.0)
        sortFields := generateSortConfig(20, sortFieldCount)
        
        start := time.Now()
        Sort(av0.Views[0], sortFields)
        time0 := time.Since(start)
        
        // 50%编辑
        av50 := generateSortBenchmarkData(rowCount, 20, 0.5)
        
        start = time.Now()
        Sort(av50.Views[0], sortFields)
        time50 := time.Since(start)
        
        // 100%编辑
        av100 := generateSortBenchmarkData(rowCount, 20, 1.0)
        
        start = time.Now()
        Sort(av100.Views[0], sortFields)
        time100 := time.Since(start)
        
        t.Logf("0%%编辑: %v", time0)
        t.Logf("50%%编辑: %v", time50)
        t.Logf("100%%编辑: %v", time100)
        
        // 验证：50%编辑应该是最慢的（双重排序开销最大）
        if time50 < time0 || time50 < time100 {
            t.Errorf("50%%编辑状态应该最慢，但实际: 0%%=%v, 50%%=%v, 100%%=%v",
                time0, time50, time100)
        }
    })
    
    // 测试2：验证多字段排序复杂度
    t.Run("VerifyMultiFieldComplexity", func(t *testing.T) {
        rowCount := 1000
        av := generateSortBenchmarkData(rowCount, 20, 0.5)
        
        // 1个字段
        sortFields1 := generateSortConfig(20, 1)
        start := time.Now()
        Sort(av.Views[0], sortFields1)
```

## 3. 优化方案

### 3.1 优化方案概述

根据问题定位，我们将优化方案分为三个优先级：P0（立即实施）、P1（短期实施）、P2（中期实施）。

### 3.2 P0优化方案（立即实施）

#### 3.2.1 缓存编辑状态

**目标**: 避免每次排序都遍历判断编辑状态

**实现位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

**实现代码**:

```go
// 位置: kernel/av/sort.go

// ItemEditStatusCache 编辑状态缓存
type ItemEditStatusCache struct {
    mu          sync.RWMutex
    cache       map[string]*EditStatusEntry
    viewVersion map[string]int64
}

type EditStatusEntry struct {
    itemID      string
    isEdited    bool
    cachedAt    time.Time
    dataVersion int64
}

var globalEditStatusCache = &ItemEditStatusCache{
    cache:       make(map[string]*EditStatusEntry),
    viewVersion: make(map[string]int64),
}

// getEditedItems 获取已编辑和未编辑的项目（使用缓存）
func getEditedItems(view *View, items []*Row) (edited, unedited []*Row) {
    cacheKey := view.ID
    
    globalEditStatusCache.mu.RLock()
    currentVersion := globalEditStatusCache.viewVersion[cacheKey]
    globalEditStatusCache.mu.RUnlock()
    
    // 检查是否需要重新计算
    needRecalc := false
    if currentVersion == 0 {
        needRecalc = true
    }
    
    if !needRecalc {
        // 尝试从缓存获取
        edited = make([]*Row, 0, len(items)/2)
        unedited = make([]*Row, 0, len(items)/2)
        
        globalEditStatusCache.mu.RLock()
        for _, item := range items {
            if entry, ok := globalEditStatusCache.cache[item.ID]; ok {
                if entry.dataVersion == currentVersion {
                    if entry.isEdited {
                        edited = append(edited, item)
                    } else {
                        unedited = append(unedited, item)
                    }
                    continue
                }
            }
            needRecalc = true
            break
        }
        globalEditStatusCache.mu.RUnlock()
        
        if !needRecalc {
            return edited, unedited
        }
    }
    
    // 缓存未命中或失效，重新计算
    edited = make([]*Row, 0, len(items)/2)
    unedited = make([]*Row, 0, len(items)/2)
    newVersion := time.Now().UnixNano()
    
    for _, item := range items {
        isEdited := isItemEdited(item)
        if isEdited {
            edited = append(edited, item)
        } else {
            unedited = append(unedited, item)
        }
        
        // 更新缓存
        globalEditStatusCache.mu.Lock()
        globalEditStatusCache.cache[item.ID] = &EditStatusEntry{
            itemID:      item.ID,
            isEdited:    isEdited,
            cachedAt:    time.Now(),
            dataVersion: newVersion,
        }
        globalEditStatusCache.mu.Unlock()
    }
    
    // 更新视图版本
    globalEditStatusCache.mu.Lock()
    globalEditStatusCache.viewVersion[cacheKey] = newVersion
    globalEditStatusCache.mu.Unlock()
    
    return edited, unedited
}

// InvalidateEditStatusCache 使编辑状态缓存失效
func InvalidateEditStatusCache(viewID string) {
    globalEditStatusCache.mu.Lock()
    defer globalEditStatusCache.mu.Unlock()
    
    delete(globalEditStatusCache.viewVersion, viewID)
}
```

**预期收益**:
- 减少40-60%的状态判断时间
- 1000条数据排序：从~600ms降低到~400ms

```go
func buildSelectOptionIndex(column *Column) map[string]int {
    cacheKey := column.ID
    
    // 尝试从缓存获取
    globalSelectOptionIndexCache.mu.RLock()
    if indexMap, ok := globalSelectOptionIndexCache.cache[cacheKey]; ok {
        globalSelectOptionIndexCache.mu.RUnlock()
        return indexMap
    }
    globalSelectOptionIndexCache.mu.RUnlock()

        indexMap[option.ID] = i
    }
    
    // 更新缓存

    globalSelectOptionIndexCache.mu.Unlock()
```

### 3.3 P1优化方案（短期实施）

#### 3.3.1 拼音缓存机制

**目标**: 缓存中文字符串的拼音转换结果，避免重复转换

**实现位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

**实现代码**:

```go
// 位置: kernel/av/sort.go

// PinyinCache 拼音转换缓存
type PinyinCache struct {
    mu    sync.RWMutex
    cache map[string]string // 中文字符串 -> 拼音字符串
    maxSize int
}

var globalPinyinCache = &PinyinCache{
    cache:   make(map[string]string),
    maxSize: 10000, // 最多缓存10000个拼音转换结果
}

// getPinyin 获取拼音（带缓存）
func getPinyin(text string) string {
    // 尝试从缓存获取
    globalPinyinCache.mu.RLock()
    if pinyin, ok := globalPinyinCache.cache[text]; ok {
        globalPinyinCache.mu.RUnlock()
        return pinyin
    }
    globalPinyinCache.mu.RUnlock()
    
    // 缓存未命中，执行拼音转换
    pinyin := util.ConvertToPinyin(text)
    
    // 更新缓存
    globalPinyinCache.mu.Lock()
    // 检查缓存大小，如果超过限制则清空一半
    if len(globalPinyinCache.cache) >= globalPinyinCache.maxSize {
        // 简单策略：清空整个缓存
        globalPinyinCache.cache = make(map[string]string)
    }
    globalPinyinCache.cache[text] = pinyin
    globalPinyinCache.mu.Unlock()
    
    return pinyin
}

// comparePinyinCached 使用缓存的拼音比较
func comparePinyinCached(str1, str2 string) int {
    pinyin1 := getPinyin(str1)
    pinyin2 := getPinyin(str2)
    
    if pinyin1 < pinyin2 {
        return -1
    } else if pinyin1 > pinyin2 {
        return 1
    }
    return 0
}

// ClearPinyinCache 清空拼音缓存
func ClearPinyinCache() {
    globalPinyinCache.mu.Lock()
    defer globalPinyinCache.mu.Unlock()
    
    globalPinyinCache.cache = make(map[string]string)
}
```

#### 3.3.2 统一排序避免双重排序

**目标**: 使用单次排序替代双重排序，通过比较函数处理编辑状态优先级

**实现位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

**实现代码**:

```go
// 位置: kernel/av/sort.go

// Sort 排序函数（优化版）
func Sort(view *View, sortFields []*SortField) error {
    if len(sortFields) == 0 {
        return nil
    }
    
    items := view.Table.Rows
    if len(items) == 0 {
        return nil
    }
    
    // 预构建选项索引（如果有选择字段）
    selectIndexMaps := make(map[string]map[string]int)
    for _, sortField := range sortFields {
        column := view.GetColumn(sortField.ColumnID)
        if column != nil && column.Type == "select" {
            selectIndexMaps[sortField.ColumnID] = buildSelectOptionIndex(column)
        }
    }
    
    // 单次排序，编辑状态作为首要排序条件
    sort.Slice(items, func(i, j int) bool {
        item1, item2 := items[i], items[j]
        
        // 首先按编辑状态排序（已编辑的排在前面）
        edited1 := isItemEdited(item1)
        edited2 := isItemEdited(item2)
        
        if edited1 && !edited2 {
            return true
        }
        if !edited1 && edited2 {
            return false
        }
        
        // 编辑状态相同，按排序字段比较
        for _, sortField := range sortFields {
            result := compareByFieldOptimized(item1, item2, sortField, selectIndexMaps)
            if result != 0 {
                if sortField.Direction == "desc" {
                    return result > 0
                }
                return result < 0
            }
        }
        
        return false
    })
    
    return nil
}

// compareByFieldOptimized 优化的字段比较函数
func compareByFieldOptimized(item1, item2 *Row, sortField *SortField, selectIndexMaps map[string]map[string]int) int {
    value1 := item1.GetValue(sortField.ColumnID)
    value2 := item2.GetValue(sortField.ColumnID)
    
    // 处理空值
    if value1 == nil && value2 == nil {
        return 0
    }
    if value1 == nil {
        return -1
    }
    if value2 == nil {
        return 1
    }
    
    // 根据字段类型比较
    switch value1.Type {
    case "text":
        text1 := value1.Text.Content
        text2 := value2.Text.Content
        
        // 使用缓存的拼音比较
        return comparePinyinCached(text1, text2)
        
    case "number":
        num1 := value1.Number.Content
        num2 := value2.Number.Content
        if num1 < num2 {
            return -1
        } else if num1 > num2 {
            return 1
        }
        return 0
        
    case "date":
        date1 := value1.Date.Content
        date2 := value2.Date.Content
        if date1 < date2 {
            return -1
        } else if date1 > date2 {
            return 1
        }
        return 0
        
    case "select":
        // 使用预构建的索引
        if indexMap, ok := selectIndexMaps[sortField.ColumnID]; ok {
            idx1 := indexMap[value1.Select.Content]
            idx2 := indexMap[value2.Select.Content]
            if idx1 < idx2 {
                return -1
            } else if idx1 > idx2 {
                return 1
            }
        }
        return 0
        
    default:
        return 0
    }
}
```

- 1000条数据排序：从~400ms降低到~250ms

#### 3.3.3 关联字段排序键预计算

**目标**: 预先计算关联字段的排序键，避免排序过程中重复计算

**实现位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

**实现代码**:

```go
// 位置: kernel/av/sort.go

// RelationSortKeyCache 关联字段排序键缓存
type RelationSortKeyCache struct {
    mu    sync.RWMutex
    cache map[string]string // rowID_columnID -> sortKey
}

var globalRelationSortKeyCache = &RelationSortKeyCache{
    cache: make(map[string]string),
}

// precomputeRelationSortKeys 预计算关联字段排序键
func precomputeRelationSortKeys(items []*Row, sortFields []*SortField, view *View) {
    globalRelationSortKeyCache.mu.Lock()
    defer globalRelationSortKeyCache.mu.Unlock()
    
    // 清空旧缓存
    globalRelationSortKeyCache.cache = make(map[string]string)
    
    for _, sortField := range sortFields {
        column := view.GetColumn(sortField.ColumnID)
        if column == nil {
            continue
        }
        
        // 只处理关联和汇总字段
        if column.Type != "relation" && column.Type != "rollup" {
            continue
        }
        
        for _, item := range items {
            cacheKey := item.ID + "_" + sortField.ColumnID
            value := item.GetValue(sortField.ColumnID)
            
            if value == nil {
                globalRelationSortKeyCache.cache[cacheKey] = ""
                continue
            }
            
            var sortKey string
            if column.Type == "relation" {
                // 使用 strings.Builder 优化字符串拼接
                var builder strings.Builder
                relations := value.Relation.Contents
                for i, relation := range relations {
                    if i > 0 {
                        builder.WriteString(",")
                    }
                    builder.WriteString(relation.Name)
                }
                sortKey = builder.String()
            } else if column.Type == "rollup" {
                sortKey = fmt.Sprintf("%f", value.Rollup.Contents)
            }
            
            globalRelationSortKeyCache.cache[cacheKey] = sortKey
        }
    }
}

// getRelationSortKey 获取关联字段排序键（从缓存）
func getRelationSortKey(rowID, columnID string) string {
    cacheKey := rowID + "_" + columnID
    
    globalRelationSortKeyCache.mu.RLock()
    defer globalRelationSortKeyCache.mu.RUnlock()
    
    if sortKey, ok := globalRelationSortKeyCache.cache[cacheKey]; ok {
        return sortKey
    }
    
    return ""
}

// Sort 排序函数（增强版，包含关联字段优化）
func SortEnhanced(view *View, sortFields []*SortField) error {
    if len(sortFields) == 0 {
        return nil
    }
    
    items := view.Table.Rows
    if len(items) == 0 {
        return nil
    }
    
    // 预计算关联字段排序键
    precomputeRelationSortKeys(items, sortFields, view)
    
    // 预构建选项索引
    selectIndexMaps := make(map[string]map[string]int)
    for _, sortField := range sortFields {
        column := view.GetColumn(sortField.ColumnID)
        if column != nil && column.Type == "select" {
            selectIndexMaps[sortField.ColumnID] = buildSelectOptionIndex(column)
        }
    }
    
    // 执行排序
    sort.Slice(items, func(i, j int) bool {
        item1, item2 := items[i], items[j]
        
        // 首先按编辑状态排序
        edited1 := isItemEdited(item1)
        edited2 := isItemEdited(item2)
        
        if edited1 && !edited2 {
            return true
        }
        if !edited1 && edited2 {
            return false
        }
        
        // 按排序字段比较
        for _, sortField := range sortFields {
            column := view.GetColumn(sortField.ColumnID)
            if column == nil {
                continue
            }
            
            var result int
            
            // 关联和汇总字段使用预计算的排序键
            if column.Type == "relation" || column.Type == "rollup" {
                key1 := getRelationSortKey(item1.ID, sortField.ColumnID)
                key2 := getRelationSortKey(item2.ID, sortField.ColumnID)
                result = strings.Compare(key1, key2)
            } else {
                result = compareByFieldOptimized(item1, item2, sortField, selectIndexMaps)
            }
            
            if result != 0 {
                if sortField.Direction == "desc" {
                    return result > 0
                }
                return result < 0
            }
        }
        
        return false
    })
    
    return nil
}
```

**预期收益**:
- 关联字段排序性能提升3-5倍
- 1000条数据关联字段排序：从~2000ms降低到~500ms
- 减少字符串拼接的内存分配

### 3.4 P2优化方案（中期实施）

#### 3.4.1 并行排序

**目标**: 对大数据集使用并行排序算法，充分利用多核CPU

**实现位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

**实现代码**:

```go
// 位置: kernel/av/sort.go

import (
    "runtime"
    "sync"
)

// ParallelSortThreshold 并行排序阈值
const ParallelSortThreshold = 1000

// SortParallel 并行排序函数
func SortParallel(view *View, sortFields []*SortField) error {
    if len(sortFields) == 0 {
        return nil
    }
    
    items := view.Table.Rows
    if len(items) == 0 {
        return nil
    }
    
    // 小数据集使用普通排序
    if len(items) < ParallelSortThreshold {
        return SortEnhanced(view, sortFields)
    }
    
    // 预计算所有优化数据
    precomputeRelationSortKeys(items, sortFields, view)
    selectIndexMaps := make(map[string]map[string]int)
    for _, sortField := range sortFields {
        column := view.GetColumn(sortField.ColumnID)
        if column != nil && column.Type == "select" {
            selectIndexMaps[sortField.ColumnID] = buildSelectOptionIndex(column)
        }
    }
    
    // 分离已编辑和未编辑项目
    edited, unedited := getEditedItems(view, items)
    
    // 并行排序两个子集
    var wg sync.WaitGroup
    wg.Add(2)
    
    go func() {
        defer wg.Done()
        parallelQuickSort(edited, 0, len(edited)-1, sortFields, view, selectIndexMaps)
    }()
    
    go func() {
        defer wg.Done()
        parallelQuickSort(unedited, 0, len(unedited)-1, sortFields, view, selectIndexMaps)
    }()
    
    wg.Wait()
    
    // 合并结果
    view.Table.Rows = append(edited, unedited...)
    
    return nil
}

// parallelQuickSort 并行快速排序
func parallelQuickSort(items []*Row, left, right int, sortFields []*SortField, view *View, selectIndexMaps map[string]map[string]int) {
    if left >= right {
        return
    }
    
    // 小数据集使用标准排序
    if right-left < 100 {
        sort.Slice(items[left:right+1], func(i, j int) bool {
            return compareItems(items[left+i], items[left+j], sortFields, view, selectIndexMaps) < 0
        })
        return
    }
    
    // 分区
    pivot := partition(items, left, right, sortFields, view, selectIndexMaps)
    
    // 并行处理左右分区（如果数据量足够大）
    if right-left > 1000 && runtime.NumCPU() > 1 {
        var wg sync.WaitGroup
        wg.Add(2)
        
        go func() {
            defer wg.Done()
            parallelQuickSort(items, left, pivot-1, sortFields, view, selectIndexMaps)
        }()
        
        go func() {
            defer wg.Done()
            parallelQuickSort(items, pivot+1, right, sortFields, view, selectIndexMaps)
        }()
        
        wg.Wait()
    } else {
        // 串行处理
        parallelQuickSort(items, left, pivot-1, sortFields, view, selectIndexMaps)
        parallelQuickSort(items, pivot+1, right, sortFields, view, selectIndexMaps)
    }
}

// partition 快速排序分区函数
func partition(items []*Row, left, right int, sortFields []*SortField, view *View, selectIndexMaps map[string]map[string]int) int {
    pivot := items[right]
    i := left - 1
    
    for j := left; j < right; j++ {
        if compareItems(items[j], pivot, sortFields, view, selectIndexMaps) < 0 {
            i++
            items[i], items[j] = items[j], items[i]
        }
    }
    
    items[i+1], items[right] = items[right], items[i+1]
    return i + 1
}

// compareItems 比较两个项目
func compareItems(item1, item2 *Row, sortFields []*SortField, view *View, selectIndexMaps map[string]map[string]int) int {
    for _, sortField := range sortFields {
        column := view.GetColumn(sortField.ColumnID)
        if column == nil {
            continue
        }
        
        var result int
        
        if column.Type == "relation" || column.Type == "rollup" {
            key1 := getRelationSortKey(item1.ID, sortField.ColumnID)
            key2 := getRelationSortKey(item2.ID, sortField.ColumnID)
            result = strings.Compare(key1, key2)
        } else {
            result = compareByFieldOptimized(item1, item2, sortField, selectIndexMaps)
        }
        
        if result != 0 {
            if sortField.Direction == "desc" {
                return -result
            }
            return result
        }
    }
    
    return 0
}
```

**预期收益**:
- 大数据集（>1000条）性能提升50-100%
- 5000条数据排序：从~600ms降低到~300ms
- 充分利用多核CPU资源

#### 3.4.2 增量排序

**目标**: 当数据变化较小时，使用增量排序而非完全重排

**实现位置**: [`kernel/av/sort.go`](../../kernel/av/sort.go)

**实现代码**:

```go
// 位置: kernel/av/sort.go

// SortState 排序状态
type SortState struct {
    mu           sync.RWMutex
    viewID       string
    sortFields   []*SortField
    sortedItems  []*Row
    itemVersions map[string]int64 // itemID -> version
    lastSortTime time.Time
}

var globalSortStates = make(map[string]*SortState)
var sortStatesMu sync.RWMutex

// SortIncremental 增量排序
func SortIncremental(view *View, sortFields []*SortField) error {
    if len(sortFields) == 0 {
        return nil
    }
    
    items := view.Table.Rows
    if len(items) == 0 {
        return nil
    }
    
    // 获取或创建排序状态
    sortStatesMu.Lock()
    state, exists := globalSortStates[view.ID]
    if !exists {
        state = &SortState{
            viewID:       view.ID,
            itemVersions: make(map[string]int64),
        }
        globalSortStates[view.ID] = state
    }
    sortStatesMu.Unlock()
    
    state.mu.Lock()
    defer state.mu.Unlock()
    
    // 检查排序字段是否改变
    sortFieldsChanged := !compareSortFields(state.sortFields, sortFields)
    
    // 检查数据变化
    changedItems := make([]*Row, 0)
    newItems := make([]*Row, 0)
    
    currentItemIDs := make(map[string]bool)
    for _, item := range items {
        currentItemIDs[item.ID] = true
        
        if oldVersion, ok := state.itemVersions[item.ID]; ok {
            // 检查版本是否变化
            if item.Version != oldVersion {
                changedItems = append(changedItems, item)
            }
        } else {
            // 新增项目
            newItems = append(newItems, item)
        }
    }
    
    // 检查删除的项目
    deletedItemIDs := make([]string, 0)
    for itemID := range state.itemVersions {
        if !currentItemIDs[itemID] {
            deletedItemIDs = append(deletedItemIDs, itemID)
        }
    }
    
    // 判断是否需要完全重排
    changeRatio := float64(len(changedItems)+len(newItems)+len(deletedItemIDs)) / float64(len(items))
    needFullSort := sortFieldsChanged || changeRatio > 0.3 || state.sortedItems == nil
    
    if needFullSort {
        // 完全重排
        err := SortEnhanced(view, sortFields)
        if err != nil {
            return err
        }
        
        // 更新状态
        state.sortFields = sortFields
        state.sortedItems = view.Table.Rows
        state.itemVersions = make(map[string]int64)
        for _, item := range items {
            state.itemVersions[item.ID] = item.Version
        }
        state.lastSortTime = time.Now()
        
        return nil
    }
    
    // 增量排序：移除变化的项目，重新插入
    sortedItems := make([]*Row, 0, len(items))
    changedItemMap := make(map[string]*Row)
    
    for _, item := range changedItems {
        changedItemMap[item.ID] = item
    }
    for _, item := range newItems {
        changedItemMap[item.ID] = item
    }
    
    deletedItemMap := make(map[string]bool)
    for _, itemID := range deletedItemIDs {
        deletedItemMap[itemID] = true
    }
    
    // 保留未变化的项目
    for _, item := range state.sortedItems {
        if !changedItemMap[item.ID] && !deletedItemMap[item.ID] {
            sortedItems = append(sortedItems, item)
        }
    }
    
    // 插入变化的项目
    selectIndexMaps := make(map[string]map[string]int)
    for _, sortField := range sortFields {
        column := view.GetColumn(sortField.ColumnID)
        if column != nil && column.Type == "select" {
            selectIndexMaps[sortField.ColumnID] = buildSelectOptionIndex(column)
        }
    }
    
    for _, item := range changedItemMap {
        // 二分查找插入位置
        insertPos := sort.Search(len(sortedItems), func(i int) bool {
            return compareItems(sortedItems[i], item, sortFields, view, selectIndexMaps) > 0
        })
        
        // 插入项目
        sortedItems = append(sortedItems[:insertPos], append([]*Row{item}, sortedItems[insertPos:]...)...)
    }
    
    // 更新视图和状态
    view.Table.Rows = sortedItems
    state.sortedItems = sortedItems
    state.sortFields = sortFields
    for _, item := range items {
        state.itemVersions[item.ID] = item.Version
    }
    state.lastSortTime = time.Now()
    
    return nil
}

// compareSortFields 比较排序字段是否相同
func compareSortFields(fields1, fields2 []*SortField) bool {
    if len(fields1) != len(fields2) {
        return false
    }
    
    for i := range fields1 {
        if fields1[i].ColumnID != fields2[i].ColumnID || fields1[i].Direction != fields2[i].Direction {
            return false
        }
    }
    
    return true
}

// InvalidateSortState 使排序状态失效
func InvalidateSortState(viewID string) {
    sortStatesMu.Lock()
    defer sortStatesMu.Unlock()
    
    delete(globalSortStates, viewID)
}
```
