# Vamana BBQ 集成任务追踪 (TikTocTak)

> **目标**: 将 BBQ (Better Binary Quantization) 集成到 Vamana 索引中。量化指标：内存压缩 32:1（512B/vec → 16B/vec），搜索加速（POPCNT 位运算），保持 95%+ 召回率。
>
> **流程**: 这是一个滚动更新的执行路线图。

> 2. 完成开发和测试。
> 3. 将其移动到"已归档/已完成"区域。
> 4. 将"中期计划"中的条目提升到"近期计划"。

---

## 🎯 核心原则

### 设计约束

1. **BBQ 自动启用策略**
   - dim > 32 时自动启用 BBQ（无需配置项）
   - 低维向量不适合二进制量化，保持原始距离计算

2. **代码复用原则**
   - 调整包文件结构，使 vamana 可复用 BBQ 模块
   - 禁止代码复制，遵循 DRY 原则

3. **两阶段搜索保证召回率**
   - 第一阶段：BBQ 粗筛，扩大候选集
   - 第二阶段：原始向量精排，保证精度

每个 Phase 完成后必须验证:
- [ ] 功能正确性：单元测试通过

## 📚 技术参考

### BBQ 核心原理

1. **二进制量化**: 将浮点向量转换为二进制码
2. **质心偏移**: 减去全局质心后量化，提高精度
3. **Hamming 距离**: 使用 POPCNT 快速计算

### 注意事项

1. BBQ 比 DiskANN 的乘积量化精度更高，但某些做法不能照搬
2. 维度限制：dim > 32 时自动启用 BBQ（无需配置项）
3. 需要两阶段搜索保证召回率
