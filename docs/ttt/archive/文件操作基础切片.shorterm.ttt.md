# 文件操作基础切片 (TikTocTak)

> **归属**: [文件浏览Dock与Monaco编辑器.ttt.md](../文件浏览Dock与Monaco编辑器.ttt.md)
> **目标**: 为文件树提供第一批真实、受授权边界保护的文件操作：新建目录、同父目录重命名、跨/同根复制。所有操作使用根 ID 与根内相对路径，不把绝对路径交给前端或 HTTP 请求。
> **流程**: 先复用 `filebrowser.Service` 的根聚合和能力范围，再调用 `fswalk` 深层写入能力；每个领域入口保留自己的参数和冲突策略，不创建带大量可选参数的万能文件操作函数。

## 参考与复用

- `SACAssetsManager` 的目录动作以目录树节点为入口，操作完成后刷新当前父目录；本切片保留该交互边界，不把查询结果卡片当作文件操作入口。
- S-Forge `kernel/filebrowser.Service` 负责根绑定、父子根归并、符号链接越界解析和 `Root.CapabilitiesForPath`。
- S-Forge `kernel/fswalk` 负责根相对路径验证、原子文件复制、目录合并、取消和链接拒绝；filebrowser 领域层只声明操作策略并映射错误。

## 冻结契约

### 新建目录

- 请求：`{rootID, path}`；`path` 是目标目录相对于根的完整路径，不能是根本身。
- 父目录必须已经存在且是目录；只创建最后一级，不隐式创建缺失父级。
- 目标已存在（文件、目录或链接）统一返回冲突；目标路径包含链接或越界返回路径错误。
- 目标所在能力范围必须允许 `write`；只读 Agent 根和只读挂载点拒绝。

### 重命名

- 请求：`{rootID, path, newName}`；`newName` 只能是一个非空路径段，不能包含 `/`、`\\`、`.` 或 `..`。
- 只允许同一父目录内重命名；根节点不能重命名；目标同名返回冲突，不覆盖已有文件或目录。
- 源和目标父目录都重新通过授权边界解析；链接入口不被跟随或改写。

### 复制

- 请求：`{sourceRootID, sourcePath, destinationRootID, destinationPath}`；源和目标都为根内相对路径。
- 允许同根和不同根复制；源仅需 `browse`，目标路径需 `write`。
- 目录采用已有 `fswalk.CopyTree` 的合并语义，普通文件采用原子覆盖语义；目标类型冲突、源/目标重叠、链接和特殊文件返回稳定错误。
- 目标父目录可由复制领域按 `fswalk` 既有策略创建；能力检查覆盖目标完整路径。

### 返回与错误

- 成功返回操作名、规范化根内路径和计数；绝不返回绝对物理路径。
- `400`：空路径、非法名称、类型不匹配；`403`：越界、链接越界或写能力拒绝；`404`：根/源不存在；`409`：目标已存在；`408`：请求取消。
- 前端操作成功后只刷新受影响的树父节点/根节点；失败保留原树状态并显示后端消息。
