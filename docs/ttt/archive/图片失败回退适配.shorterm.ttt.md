# 图片失败回退适配（TikTocTak）

> 归属：[`文件浏览Dock与Monaco编辑器.ttt.md`](../文件浏览Dock与Monaco编辑器.ttt.md)

## 目标

对齐 `D:\dev\SACAssetsManager` 的图片加载语义：原图优先，缩略图作为受控回退，加载过程中保持稳定布局，失败时显示应用占位而不是浏览器破图标。

## 实现

- `app/src/asset/assetUrl.ts` 解析文件浏览器内容 URL，提取 `rootID` 与根内相对路径，生成同源 `/api/s-forge/file-browser/thumbnail` 地址。
- `app/src/components/panels/imageEditor.vue` 在原图加载失败时切换同根缩略图；资源地址变化会重置回退状态。
- `app/src/asset/components/AssetCard.vue` 与现有资源卡片样式继续使用透明像素占位和稳定最小高度。
