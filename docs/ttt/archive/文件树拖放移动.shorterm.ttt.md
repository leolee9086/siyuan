# 文件树拖放移动（TikTocTak）

> 归属：[`../文件浏览Dock与Monaco编辑器.ttt.md`](../文件浏览Dock与Monaco编辑器.ttt.md)

## 目标

把文件树已有的拖放视觉交互接入真实文件移动能力。拖放只接受树/画廊产生的 `application/x-sforge-file` 数据，后端继续以 `rootID + 根内相对路径` 作为唯一地址，不向前端暴露绝对路径。

## 冻结契约

- `sourceRootID`、`sourcePath`：来源授权根和来源根内路径。
- `destinationRootID`、`destinationPath`：目标授权根和完整目标根内路径（包含被移动项名称）。
- 来源只要求浏览能力；目标要求最具体挂载范围具有写能力。
- 根本身、目标已存在、源/目标重叠、越界路径、链接入口和受限挂载都由领域层拒绝。
- 成功后刷新来源父目录和目标父目录，保留树的选择与展开状态。
