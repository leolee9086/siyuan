# 批量文件操作 (TikTocTak)

> **归属**: [文件浏览Dock与Monaco编辑器.ttt.md](../文件浏览Dock与Monaco编辑器.ttt.md)
> **范围**: 文件树共享多选到批量删除的完整契约，不把单项操作改造成带大量可选参数的万能入口。

## 参考语义

- SACAssetsManager 的批量菜单以当前选择集为输入，统一确认后执行，并保留逐项结果。
- S-Forge 继续由 `filebrowser.Service` 负责根 capability，`fswalk.Walker.RemoveTree` 负责每个目标的链接预检、取消和递归删除。
- 树仍是目录树操作入口；资源结果卡片不直接承担文件树批量删除状态。

## 冻结契约

- 请求：`POST /api/s-forge/file-browser/operations/delete-batch`，只接受 `{items:[{rootID,path}]}`。
- 只允许 1-100 项；同一根内规范化后重复地址在任何写入前整体拒绝。
- 每项独立通过根授权和根内路径校验；执行顺序按根分组、路径深度降序，已选父目录和子项不会因顺序造成伪失败。
- 响应保留输入顺序，返回 `successCount`、`failureCount` 和每项 `result`/`error`；部分失败显式呈现，不伪造整体成功。
- 根本身、越界路径、只读 capability、链接和特殊文件继续使用单项删除的稳定错误语义。
