# 文件根父子归并（TikTocTak）

> 目标：当工作空间根、Agent 任务目录或重复绑定的物理位置存在父子关系时，文件树只呈现一套连续目录状态，同时保留每个绑定来源、原始 root ID 和各自能力边界。

## 语义冻结

- [x] 规范化绝对路径后按完整路径段判断祖先；Windows 路径大小写不敏感，`D:\\dev2` 不得被当成 `D:\\dev` 的子路径。
- [x] 优先使用现有真实路径解析结果判断 junction、symbolic-link 和别名；解析失败或失效绑定保持独立可见，仅在完整段边界内归并。
- [x] 完全相同的真实路径合并为一个根，所有 Agent 会话来源保留并稳定排序。
- [x] 父根与子根只保留最小祖先作为顶层展示根；子根进入挂载描述，并可用原 root ID 解析到自身路径，能力按最具体路径范围计算。
- [x] 兄弟路径、相似前缀路径、不同卷标和越界链接不归并。
- [x] 查询 `allRoots` 只扫描展示根集合，避免同一物理文件通过父根和子根重复返回；显式旧子根 ID 仍可请求其原始范围。
