# 文件删除与确认 (TikTocTak)

> **归属**: [文件浏览Dock与Monaco编辑器.ttt.md](../文件浏览Dock与Monaco编辑器.ttt.md)
> **范围**: 文件树删除操作从 Walker、filebrowser 服务、Kernel API 到 Dock 菜单和确认对话框的完整链路。

## 验收边界

- 删除请求只携带 `rootID` 与根内相对 `path`，禁止根本身、越界路径、符号链接和非普通文件。
- 删除目录采用 `fswalk.Walker.RemoveTree` 的预检语义，发现链接或读取错误时不产生部分删除。
- 删除权限按父根挂载中最具体的 capability 判定；只读或失效根不暴露删除入口。
- UI 必须在实际删除前显示明确确认，成功后刷新父目录并清理已删除节点的选择；失败只显示明确错误。
- API/service、菜单、仓储和真实 Vue 交互均有聚焦测试，证据回写主 TTT 后本子任务移入 archive。
