# 文件树批量复制移动 (TikTocTak)

> **归属**: [文件浏览Dock与Monaco编辑器.ttt.md](../文件浏览Dock与Monaco编辑器.ttt.md)
> **范围**: 文件树共享多选到批量复制/移动的完整契约；单项 `Copy`/`Move` 保持原有目标文件路径语义，批量入口使用已存在的目标目录。

## 参考语义

- 选择集仍来自文件树共享选择端口，资源画廊不承担树操作状态。
- 批量复制使用独立目标目录输入；每个源项保留自身名称，跨根授权仍由 `filebrowser.Service` 决定。
- 树拖放保留单项移动兼容行为；当拖动项属于多选集时携带多个 `{rootID,path}`，Panel 使用批量移动接口并保留逐项结果。
- 具体目录遍历、链接限制、重叠检测、冲突和原子写入继续由 `fswalk.Walker` 和单项领域操作负责，批量层不引入万能读写函数。

## 冻结契约

- `POST /api/s-forge/file-browser/operations/copy-batch`
- `POST /api/s-forge/file-browser/operations/move-batch`
- 请求：`{items:[{rootID,path}], destinationRootID, destinationPath}`；目标路径是已存在目录，空路径表示目标根。
- 只允许 1-100 项；同一根内规范化后重复地址整体拒绝；响应按输入顺序保留逐项 `result` 或 `error`，并提供 `successCount`/`failureCount`。
- 批量执行按根和路径深度降序安排，单项错误不会抹掉已完成项；取消、授权、越界、链接、冲突和目录类型错误沿用单项领域错误映射。
