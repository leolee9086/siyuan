# 图片预览与缩略图适配

## 目标

让文件浏览器的图片卡片、图片预览页签和资源编辑器都使用同一份可寻址的文件 URL；对齐 `D:\dev\SACAssetsManager` 的做法：路径参数逐项 URL 编码，缩略图由服务端生成并返回真实图片 MIME，原图/预览使用可直接交给浏览器的同源 URL。

- [x] 修复 s-forge 资源编辑器对根相对文件浏览 URL 的解析，避免拼接到 `baseURL` 后请求应用壳文本。
- [x] 验证缩略图和原图响应状态、MIME、字节内容，以及空格、中文、嵌套路径。
