# 文件浏览树与瀑布流页签（TikTocTak）

> **状态**：进行中
> **归属**：[`文件浏览Dock前端.shorterm.ttt.md`](文件浏览Dock前端.shorterm.ttt.md)
> **范围**：把文件树 Dock 与资源查询/瀑布流结果页签按 SACAssetsManager 的最终结构接线；不把查询结果继续嵌入树 Dock。

## 参考行为冻结

- 左侧/侧边 Dock 只负责工作空间根、全部历史 Agent 绑定根、递归目录树、选择和目录导航。
- 双击根或目录打开独立资源结果页签；页签通过 `{rootID, path}` 接收范围，不携带绝对路径。
- 结果页签复用 s-forge 现有 `TabRegistry`、`VirtualMasonryGrid`、`AssetCard` 和文件属性/打开端口；查询筛选仍由 `FileBrowser.query` 领域仓储负责。
- 标签、星级、注释和调色板投影显示在卡片；颜色/标签查询调用后端索引，不做前端结果猜测。
