# 文件复制工作流 (TikTocTak)

> **归属**: [后端文件系统遍历统一抽象](后端文件系统遍历统一抽象.shorterm.ttt.md)
> **目标**: 移除 MCP 与 CLI 各自维护的递归复制实现；保留目录合并、文件覆盖和遇错停止语义，由 `fswalk.CopyTree` 负责根边界、枚举、目录创建、流式复制、原子替换、取消和错误归一化。

## 契约

- 源和目标都通过已绑定的 `fswalk.Walker` 表示，公开入口只接收各自根相对路径。
- 调用方只声明目录剪枝和文件选择；不读取文件、不创建目录、不打开文件句柄。
- 默认不跟随链接；源树中的链接被报告为错误，目标路径中的链接不能被穿透。
- 目录目标采用合并语义，普通文件目标采用覆盖语义；目标类型冲突直接失败。
- 源目录与目标目录存在相同或包含关系时拒绝，避免复制过程中改变遍历源。
