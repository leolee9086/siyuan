# 内容字节搜索工作流 (TikTocTak)

> **归属**: [后端文件系统遍历统一抽象](后端文件系统遍历统一抽象.shorterm.ttt.md)
> **目标**: 将 `search.FindAllMatches` 的递归发现和文件读取移入独立的 `fswalk` 字节搜索入口；保留搜索领域的目标集合、结果路径转换和调用方业务语义，不复用 UTF-8 行搜索或文本替换策略。

## 既有语义

- 空根或空目标返回空结果。
- 只扫描普通文件，不跟随符号链接；单文件读取失败降级为无命中。
- 目标按首字节索引，支持跨 64 KiB 块匹配；每个文件内同一目标只返回一次。
- 读取 worker 并发，结果顺序不作为业务契约。

## 实施

- [x] `fswalk.SearchByteTargets` 聚焦入口与真实跨块、二进制、去重、筛选、链接、越权和取消测试。
- [x] `kernel/search/find.go` 删除目录遍历、文件打开、buffer/tail 和 worker 管理，仅保留目标输入与领域结果路径适配。
- [~] `go test ./fswalk ./search -count=1` 通过；两个模型调用点仍使用原公开 API，待 `assetmeta` 迁移后执行相关模型包回归并回写主 TTT。
