> **归属**: [文件浏览Dock与Monaco编辑器.ttt.md](../文件浏览Dock与Monaco编辑器.ttt.md)
> **目标**: 在既有 Dock/Files/菜单/页签体系内提供文件根、树、画廊、筛选、标签、颜色、预览和操作界面。

## 复用入口

- 通过 `dock.factory.ts` 注册一个内建 model，沿用 `dock.init.ts` 的缺失面板恢复和布局持久化。
- 复用通用 `Tree` 与 `Files` 已验证的 B3 树视觉、焦点类、折叠箭头、右键菜单和键盘导航原语；任意文件树不复用思源文档节点协议，也不声称通用 `Tree` 已提供节点级懒加载。
- 复用 `AssetMasonryDialog`、`asset` 标签 API、全局菜单、`openEditorTab`/`openBy` 和既有图标，不引入第二套按钮/菜单系统。

### M1.2 契约决策

- `stat` 返回服务端校验后的文件项、MIME、预览类型、稳定 revision 和受控内容 URL；前端不依据根的绝对位置自行拼接文件路径。
- `preview` 只返回有界文本及编码、截断状态，避免把大文件整体载入 Dock；图片、音频、视频和 PDF 通过 `content` 流进入现有 `Asset` 页签。
- `content` 使用 root ID 与逐段编码的相对路径，支持 HTTP Range、mtime 和 MIME；HTML 等主动内容不进入 iframe 预览。
- 文本和其他格式使用已有 `TabRegistry`/`Custom`/Vue 挂载生命周期创建只读预览页签，后续 Monaco 里程碑在同一文件身份契约上增加编辑模型，不建立临时第二协议。

## 界面状态

- 根列表：工作空间、每个 Agent 任务目录、权限徽标、绝对位置、失效提示。
- 工具栏：面包屑、搜索、递归开关、视图切换、排序、扩展名/标签/颜色/星级过滤、刷新和取消。
- 内容区：树/列表/网格/瀑布/表格，支持虚拟化、键盘多选、框选、拖放和空/加载/错误/部分结果。
- 详情区：预览、尺寸、大小、mtime、标签编辑、标签颜色、星级、注释、调色板和来源。
- 操作菜单：打开、编辑、复制路径、复制/移动/重命名/删除、上传、打包下载、外部打开；只读根隐藏写操作。
