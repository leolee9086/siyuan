# 外部根图片调色板检索（TikTocTak）

> 归属：[`文件浏览Dock与Monaco编辑器.ttt.md`](../文件浏览Dock与Monaco编辑器.ttt.md)
> 目标：让工作空间和 Agent 绑定根中的未索引图片参与真实 RGB/HSL/比例调色板检索。

## 参考与边界

- SACAssetsManager 最终参考提交：`94c8534a`；颜色 provider 负责产生调色板数据，结果层按同一调色板色块匹配。
- s-forge 现有 `assetmeta` 已有 `Palette`、索引 SQL 条件和 `ExtractPaletteFromDecodedImage`；文件查询默认扫描只覆盖无元数据门槛查询。
- SACAssetsManager 的真实颜色查询使用颜色倒排索引和 CIEDE2000 阈值 `<20`；它没有证据支持 RGB 欧氏距离作为最终匹配规则。
- 文件打开与解码继续由 `fswalk` 深模块完成；本子任务不把解码回调接入 `filequery`，避免在生产代码中保留未验证的按需扫描实验。

## 冻结契约

- 颜色查询只对已有索引调色板执行；未索引图片不伪装成“没有匹配”，外部根按需提取要另立有真实 provider 证据的切片。
- `PaletteMatches` 与 SQLite `ciede2000_rgb` 谓词共享 `kernel/color` 的 RGB -> Lab(D65) -> CIEDE2000 实现。
- `Tolerance` 是 Delta-E 阈值，省略或为零使用参考默认值 20；HSL 环形色相、S/L 和最小比例仍由同一调色板色块满足。
- 根 ID 与根内相对路径由 `filequery`/`filebrowser` 解析，前端结果仍是 `{rootID, path}`。
- 已有索引记录继续优先提供标签、星级、注释等元数据；未索引图片按需提取尚未进入生产查询链。
