# 文件加载器与预览策略（TikTocTak）

> **归属**：[`文件浏览Dock前端.shorterm.ttt.md`](文件浏览Dock前端.shorterm.ttt.md)
> **范围**：把 SACAssetsManager 最终内置加载器序列映射到 S-Forge assets 领域；卡片缩略图和主要预览页签共享同一格式策略。

## 参考实现冻结

- `94c8534a` 的最终内置缩略图序列为 `svg`、`sharp`、`sy`、`d5m`、Windows `systermThumbnailWin64`。
- `pdf`、`eagle`、`onlyName` 属于历史生成器，不能误记为最终注册 Provider；系统 Provider 失败时不得把文件图标伪装成原图缩略图。
- `svg` 返回 SVG 原始字节；`d5m` 读取压缩包内 `icon.png`；栅格图片由纯 Go 图像 Provider 处理；Windows 系统 Provider 处理已安装 Shell 扩展支持的格式。
