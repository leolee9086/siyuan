## 不变量

- 不删除 `imports.ts` 网关，也不通过 lint 排除或动态导入隐藏依赖。
- 类型依赖实现本身不是问题；生产模块对具体 class 的运行时依赖才需要迁移到初始化、工厂或契约校验边界。
- 不按单个函数参数创建局部接口；领域抽象必须覆盖该聚合根的完整公开职责。
- `IPluginRuntime` 等已确认错误抽象不再恢复；插件使用官方 `siyuan.Plugin` 类型。
- npm `siyuan@1.2.3` 是插件生态与共享数据格式的强制兼容边界；清理碎片时不得以本地接口替代、删减或绕开官方契约。
- `MobileOutline*Port`、`MobileFiles*Port` 等现存端口族不得机械合并；只有当其职责属于同一完整领域根且合并不引入耦合时才归并。
- 不使用 `unknown` 掩盖具体领域身份；外部数据边界使用已有官方/配置类型和显式守卫。
- 每批修改必须有专门测试目录中的兼容校验，运行行为保持不变。
- 每批完成后更新本文、运行 `git diff --check`、相关测试和 Madge/Tarjan SCC；已解决文件及时暂存。
