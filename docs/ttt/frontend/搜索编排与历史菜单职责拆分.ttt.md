## 不变量

- 搜索词必须先前置、去重，再按 `config.search.limit` 截断并立即更新内存状态。
- 空资源搜索词不更新内存或写盘。
- 普通、替换和资源历史菜单的选择动作保持独立，不以参数分支强行合并不同交互。
- 不使用回调注入、事件或动态导入隐藏搜索流程依赖。
- 旧公开保存 API 只允许导出同一函数身份，不复制实现。
- `imports.ts` 必须直达真实声明或唯一实现。
