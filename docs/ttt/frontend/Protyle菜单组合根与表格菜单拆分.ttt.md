## 不变量

- `imports.ts` 用于显式暴露子域外依赖，不反向导出具体业务实现；没有隔离价值的单消费子网关直接删除。
- 表格操作函数、事务和 Dialog 实现保持唯一，不复制算法。
- 菜单项顺序、标识、文案、选区恢复与事务 HTML 快照保持一致。
- 工厂只负责无状态构造和注册，禁止通过工厂闭包持有跨调用状态；跨调用状态由统一 Symbol 注册表拥有，并支持枚举、替换和显式重置。
- 单次菜单构造中的局部派生值与事件参数不升级为全局状态；普通事件处理器仅捕获该菜单实例的短生命周期上下文。
- 涉及 class 时依赖完整领域根并由 `LooksLike.types.ts` 校验，不创建调用点碎片接口。
- 测试位于 `app/test`。
