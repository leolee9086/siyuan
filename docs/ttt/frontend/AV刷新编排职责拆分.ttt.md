## 不变量

- `refreshAV` 公开签名和 transaction 调用语义保持不变。
- `refreshTimeouts` 与 `addingFocusTokens` 继续按 Protyle/AV 身份隔离，不迁入工厂闭包。
- 不用动态导入、事件转发、宽泛类型或参数回调隐藏静态依赖。
- 每个提取职责复用唯一行为实现；`imports.ts` 直接指向真实声明或实现，不串联其它网关。
- 不把操作分支重排、异步化或合并成配置表，除非专项测试证明运行时顺序等价。
