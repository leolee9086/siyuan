# 条件编译警告修复执行跟踪 (TikTocTak)

> **目标**: 为桌面端特有代码添加条件编译保护，消除移动端构建时的编译警告，确保代码在移动端和桌面端的正确隔离。
>
> **流程**: 这是一个滚动更新的执行路线图。
> 1. 从"近期计划"中认领一个任务。
> 2. 完成开发和测试。
> 3. 将其移动到"已归档/已完成"区域。
> 4. 将"中期计划"中的条目提升到"近期计划"。

---

## 🎯 核心原则

### 条件编译规则
- 使用 `/// #if !MOBILE` 和 `/// #endif` 包裹桌面端特有代码
- 引用 `getAllModels`, `getAllTabs`, `getAllWnds`, `getAllDocks` 等函数的代码必须保护
- 依赖 `window.siyuan.layout` 的代码必须保护
- `Tab` 类在移动端不可用，引用处需要保护

### 验证检查清单
- [ ] 移动端构建无编译警告
- [ ] 桌面端功能正常运行
- [ ] 条件编译块语法正确
- [ ] 相关 import 语句已包裹

---

## ℹ️ 如何维护此文档

1. **完成归档**：任务完成后，**必须**剪切粘贴到【已归档】列表，并打上 `[x]` 和日期。
2. **补充弹药**：当【近期计划】空了，从【中期计划】里挑选任务挪上去。
3. **因地制宜**：如果发现计划不合理，随时修改或删除。
4. **数据驱动**：用数据说话，不凭感觉。
