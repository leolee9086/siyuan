# 移动键盘工具栏状态与生命周期拆分 (TikTocTak)

## 最终目标

将移动键盘工具栏的原生桥接、关闭锁、计时器、手势、可见性、渲染和事件监听拆为明确子域；全部跨调用状态由统一 Symbol 注册表拥有，事件监听器不以工厂闭包保留状态，工具栏 UI 行为与原生平台语义保持不变。

- [x] 迁移原生键盘关闭锁、工具栏计时器、util 模式、渲染阻断和手势状态。
- [x] 将 `activeBlur`、`hideKeyboardToolbar` 和移动原生键盘能力迁入独立键盘子域。
- [ ] 拆分工具栏渲染、显示和初始化监听器的遗留巨型函数。

## 下一步任务

1. 为 show/hide、关闭锁和插件通知增加 DOM 行为测试。
2. 拆分动态按钮状态渲染与选区滚动处理。
3. 将横竖屏 resize 处理提取为可测试的尺寸状态转换。
4. 为监听器建立显式安装/销毁生命周期，防止重复初始化。

## 不变量

- 工厂和初始化函数不通过闭包持有跨事件状态；事件处理器每次从统一注册表读取当前状态。
- 注册表状态可枚举、替换和显式重置，重置时取消待执行计时器。
- `activeBlur` 锁定期保持可见 warning，不静默关闭或忽略失败。
- Android、Harmony 和移动浏览器分支语义保持不变。
- `imports.ts` 显式暴露真实外部依赖，不保留旧路径兼容转发。
- 测试位于 `app/test`。
