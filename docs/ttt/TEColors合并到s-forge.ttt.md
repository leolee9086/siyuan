# TEColors 合并到 s-forge 内部 (TikTocTak)

> **目标**: 将 `D:\dev\TEColors` 的全部本地用户能力合并到 s-forge 内部，形成不依赖第三方插件加载机制的原生颜色工具。范围包括块颜色、文字行内样式、内置与自定义色板、主题变量分析、笔记颜色复用、图片取色、多算法分析、对比色计算、色板导入导出、色卡预览与图片导出。GPT-4o/LLM 图片取色已明确推迟到远期，不属于当前验收范围。
>
> **流程**: 先完成现状调查和架构落位，再按颜色应用、色板管理、图片分析、导出和验证阶段滚动推进；每个阶段完成后同步更新本记录。

## ℹ️ 维护说明

这是一个长期存活的功能合并记录。实现必须直接进入 s-forge 的前端/内核代码体系，不创建 `extensions/plugins` 下的插件，不通过插件目录动态加载，也不保留仅供演示的未接线实现。

开始每个阶段前先在对应任务后记录认领信息；完成并验证后，将任务移动到“已归档/已完成”，保留实现文件、测试和已知限制的链接。

## 🔁 同步规则

- 实现开始、实现完成、运行验证和发现阻塞时，必须在同一工作阶段更新本记录。
- 代码未通过对应验收前，只更新“当前状态”和更新日志，不得勾选完成。
