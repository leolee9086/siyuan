# Vamana 库测试执行与性能诊断 (TikTocTak)

> **目标**: 执行 `kernel/vectordb/vamana` 包全部测试，收集召回率等性能指标，诊断是否符合正确实现的向量搜索库应有表现。量化指标：召回率 ≥ 70%（标准 SIFT 数据集，efSearch=100）。
>
> **流程**: 这是一个滚动更新的执行路线图。
> 1. 从"近期计划"中认领一个任务。
> 2. 完成开发和测试。
> 3. 将其移动到"已归档/已完成"区域。
> 4. 将"中期计划"中的条目提升到"近期计划"。

## 核心原则

- 以测试输出数据为唯一诊断依据，不凭主观判断
- 召回率是向量搜索库的核心质量指标

### 验证检查清单

- [ ] 全部测试通过（或已知失败项有合理解释）
- [ ] 召回率数据已收集并与基准对比
- [ ] 诊断结论有数据支撑

## ℹ️ 如何维护此文档

1. **完成归档**：任务完成后，**必须**剪切粘贴到【已归档】列表，并打上 `[x]` 和日期。
2. **补充弹药**：当【近期计划】空了，从【中期计划】里挑选任务挪上去。
3. **因地制宜**：如果发现计划不合理，随时修改或删除。
4. **数据驱动**：用数据说话，不凭感觉。
