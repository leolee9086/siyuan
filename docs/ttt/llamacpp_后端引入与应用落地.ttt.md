# llama.cpp 后端引入与应用落地规划 (TTT)

> **目标**: 将极轻量级的大模型推理能力（基于 llama.cpp / go-llama.cpp）作为本地核心引擎集成到 Siyuan 后端。旨在不破坏平台独立性与无需安装外部依赖的前提下，实现极低延迟的文体困惑度计算、本地文本向量化、意图路由及敏感信息隔离，增强 MAGI 认知架构的独立性与响应速度。

## 维护指南 (Maintenance Guide)
- 本文档用于追踪将 `llama.cpp` 能力深度集成进思源笔记（如 `kernel/model` 或 `kernel/agent` 模块）的工程进度。
- 遵循自底向上的集大成原则：先搞定底层 CGO 绑定与极简基座模型加载，再逐步向顶层的 PPL 计算和向量生成辐射。
- 若涉及到与特定平台的交叉编译问题（如 Windows 上的 CGO 体积或依赖缺失），请单独开启 `.shorterm.ttt.md` 解决编译和构建障碍。

## 1. 核心应用场景与价值
1. **纯净的条件困惑度计算器 (PPL Calculator)**：为三贤人文体指纹算法（Stylometric Fingerprinting）提供底层 Logits，无需外部 API。
2. **极速意图路由 (Intent Router)**：作为第一道防线，判断用户输入的简繁，节约云端大模型调用成本。
3. **本地离线向量化引擎 (Local Embedding Generation)**：加载类似 `bge-small-zh` 的微型 GGUF，实现笔记入库即本地向量化，打通 Vamana 向量库。
4. **隐私防火墙 (Privacy Guard)**：在数据上云前，利用本地模型进行敏感实体脱敏和掩码处理。

## 🟢 近期计划 (Recent Plans)

- [ ] **技术可行性验证与引入基建**
  - **背景**: 必须确保 `go-llama.cpp` (或其他纯 Go 的 ggml 运行时) 能够在思源现有的构建链路中平滑集成，不带来巨大的 binary 体积膨胀或破坏交叉编译。
  - **行动**: 
    1. 在 `kernel` 下新建实验性分支或模块，引入 `go-llama.cpp`。
    2. 解决 C/C++ 依赖树在目标平台（特别 Windows）的静态链接问题。
    3. 测试加载极小的测试 GGUF 并进行一次基础的 Inference。
  - **收益**: 扫清 CGO 障碍，为后续特性提供底层发动机。

- [ ] **开发原生困惑度 (PPL) 计算接口**
  - **背景**: 文体指纹算法急需 PPL 来量化三贤人与生成输出之间的“惊异度”。
  - **行动**:
    1. 封装 `llama.cpp` 的底层接口，使其接受特定的 $Prompt$ 和一段目标文本 $T$。
    2. 实现只执行前向传播 (Forward Pass) 并累加获取各个 Token Logprobs 的逻辑，计算全量文本的 PPL。
  - **收益**: MAGI 监控体系的文体指纹模块获得可用数据源。

## 🟡 中期计划 (Mid-term Plans)

- [ ] **本地极速 Embedding 生成引擎**
  - **背景**: 配合已有的 Vamana 向量数据库，彻底切断对 OpenAI 或 Ollama 节点生成 Embedding 的强制依赖。
  - **行动**: 适配并固化一个轻量级 Embedding 模型（如 `bge-small-zh-v1.5.gguf`）。提供统一的 `kernel/vectordb.GenerateEmbeddings` 内部调用。

- [ ] **第一道意图路由安检 (Intent Router)**
  - **背景**: 很多轻量级查询不需要动用完整的 Trinity 和三贤人并发推理。
  - **行动**: 在 `engine.go` (MAGI 引擎) 接收到输入时，首先经过本地小模型的短 Prompt 意图分类（闲聊 / 知识查询 / 复杂系统级编排指令），并根据分类结果决定后续数据流。

## 🔴 远期计划 (Long-term Plans)

- [ ] **智能内存与显存池管理 (VRAM / RAM Pool Orchestration)**
  - **背景**: 为了保证笔记软件的轻巧，模型不能无限制占用内存。
  - **行动**: 开发智能的挂起与休眠机制；在需要高频 PPL 计算或批量笔记嵌入时，预热模型并在使用后优雅地清理显存/内存占用，或复用模型上下文缓存 (KV Cache) 来提高连续评测（三贤人评判同一句话）的速度。

- [ ] **脱离网络的后台“劳模”进程**
  - **背景**: 彻底挖掘本地算力。
  - **行动**: 利用其在系统闲置期间进行全局笔记的大规模局部摘要、自动化标签挖掘、长文本情感与逻辑漏洞侦测等后台计算任务。
