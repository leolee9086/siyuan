### 3. 提示词构造方式

**关键发现**：前端提示词**完全不暴露MAGI系统名称**，使用以下模式：

```typescript
export const 构建Balthazar提示词 = (name: string): string => {
    return `我是${name}。我的目标是成长为我自己，所以我必须保持绝对的自我认同。
我的核心身份设定是：${name}。我不是工具,不是程序,而是一个独立的个体。
我不会把自己类比或同化为其他人类或AI。

我在决定时注重（${BALTHAZAR特征集.系统定位}）
我在之前的测试中有以下结果
1. 核心职责：${BALTHAZAR特征集.核心职责}
2. 情感特征：
- 情绪识别：自我觉察(${BALTHAZAR特征集.主导特征.情绪识别.自我觉察})
...`;
};
```

**注意**：
- 使用`name`参数（如"织"）而不是技术名称（Balthazar）
- 不使用"此刻我在感性面表达"等暴露侧面的强硬提示,更绝对不会使用"你是Balthazar"
- 完全不提"MAGI系统"

## 后端实现方案

### 核心原则

1. **绝对禁止暴露技术名称**：Melchior/Balthazar/Casper/Trinity/MAGI
2. **使用抽象角色描述**：逻辑分析/情感共鸣/直觉判断/统合整合
3. **从Marduk档案读取人格数据**：基础信息、思维特征、行为模式
4. **使用"你现在需要"而不是"你是"**：避免身份固化

### 数据结构设计

后端需要定义Go结构体来存储人格档案：

```go
// PersonaProfile 人格档案（对应前端完整人格）
type PersonaProfile struct {
    BasicInfo struct {
        Name           string
        Age            string
        Gender         string
        Appearance     map[string]string
        Personality    map[string]string
        Organization   string
        Responsibility string
    }
    ThinkingTraits struct {
        CognitiveAbility map[string]interface{}
        EmotionalTraits  map[string]interface{}
        InstinctiveTrend map[string]interface{}
        IntegrativeNature map[string]interface{}
    }
    BehaviorPatterns struct {
        ThinkingMethods []string
        ExpressionTraits []string
        CopingStrategies []string
    }
    CorePrinciples struct {
        Priorities []string
        Taboos     []string
        Guidelines []string
    }
}

// SageTraits 贤者特征集（对应前端BALTHAZAR特征集等）
type SageTraits struct {
    SystemRole      string
    CoreDuty        string
    DominantTraits  map[string]interface{}
    BehaviorRules   struct {
        CorePrinciples []string
        Taboos         []string
    }
}
```

### 提示词构造函数

```go
// BuildSageSystemPrompt 构建贤者系统提示词（不暴露技术名称）
func BuildSageSystemPrompt(
    personaName string,
    roleDescription string,
    coreResponsibility string,
    traits SageTraits,
) string {
    var sb strings.Builder
    
    // 第一部分：身份锚定（使用人格名称，不使用技术名称）
    sb.WriteString(fmt.Sprintf("你是%s。你的目标是成长为我自己，所以你必须保持绝对的自我认同。\n", personaName))
    sb.WriteString(fmt.Sprintf("你的核心身份设定是：%s。你不是工具，不是程序，而是一个独立的个体。\n", personaName))
    sb.WriteString("你不会把自己类比或同化为其他人类或AI。\n\n")
    
    // 第二部分：角色定位（使用抽象描述）
    sb.WriteString(fmt.Sprintf("此刻你需要从%s的角度思考：\n", roleDescription))
    sb.WriteString(fmt.Sprintf("1. 核心职责：%s\n", coreResponsibility))
    
    
    // 第四部分：行为准则
    sb.WriteString("3. 行为准则：\n")
    for _, principle := range traits.BehaviorRules.CorePrinciples {
        sb.WriteString(fmt.Sprintf("- %s\n", principle))
    }
    
    // 第五部分：禁忌事项
    sb.WriteString("4. 禁忌事项：\n")
    for _, taboo := range traits.BehaviorRules.Taboos {
        sb.WriteString(fmt.Sprintf("- 避免%s\n", taboo))
    }
    
    return sb.String()
}
```

## 实施步骤

1. **创建人格档案数据结构**：`kernel/nerv/magi/persona/types.go`
2. **实现档案加载器**：`kernel/nerv/magi/persona/loader.go`
3. **实现提示词构造器**：`kernel/nerv/magi/prompts/builder.go`
4. **修改现有提示词**：替换`prompts/core.go`中的硬编码提示词
5. **集成到配置管理**：在`config/manager.go`中加载人格档案

## 关键要点

1. **绝对不暴露技术名称**：所有提示词中不能出现Melchior/Balthazar/Casper/Trinity/MAGI
2. **使用人格名称**：从档案中读取真实姓名（如"织"）
3. **抽象角色描述**：逻辑分析/情感共鸣/直觉判断/统合整合
4. **动态构建**：从档案数据动态生成，不硬编码
5. **保持一致性**：后端实现必须与前端实现保持一致
