# 修复 color.ts 中的 ESLint 错误

## 任务描述
修复 app/src/util/color.ts 文件中的 ESLint 错误，主要是关于函数内部定义命名函数的问题。

## 问题分析
1. 在 `genRandomColor` 函数内部定义了 `hslToHex` 命名函数
2. 在 `hslToHex` 函数内部定义了 `f` 命名函数
3. 这违反了"具名函数内部不得定义任何具名函数"的规则

## 修复计划
- [ ] 将 `hslToHex` 函数提取到模块顶层
- [ ] 将 `f` 函数提取为独立的顶层函数，并重命名为更具描述性的名称
- [ ] 更新函数调用以使用提取后的函数
- [ ] 验证修复后的代码功能正确性
