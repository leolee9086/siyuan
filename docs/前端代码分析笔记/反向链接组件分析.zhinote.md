# 反向链接 Dock 组件代码结构分析

## Backlink.ts 核心结构

### 类属性

```typescript
export class Backlink extends Model {
    public element: HTMLElement;           // Dock 面板容器
    public inputsElement: NodeListOf<HTMLInputElement>;  // 过滤输入框
    public type: "pin" | "local";          // 固定在 Dock 还是独立 Tab
    public blockId: string;                // 当前关注的块 ID
    public rootId: string;                 // 文档 root ID (local 模式必须)
    public tree: Tree;                     // 反向链接树
    public mTree: Tree;                    // 提及树 (mention)
    private notebookId: string;            // 笔记本 ID
    public editors: Protyle[] = [];        // 展开时创建的编辑器实例
    public status: {...};                  // 状态缓存 (滚动位置、展开状态等)
}
```

### API 调用

```typescript
// 主数据获取
fetchPost("/api/ref/getBacklink2", {
    sort: "...",           // 反向链接排序方式
    mSort: "...",          // 提及排序方式
    k: "...",              // 反向链接过滤关键词
    mk: "...",             // 提及过滤关键词
    id: this.blockId,      // 当前块 ID
})

// 展开后获取文档内反向链接
fetchPost("/api/ref/getBacklinkDoc", {
    defID: this.blockId,     // 定义块 ID
    refTreeID: docId,        // 引用来源文档 ID
    highlight: !isSupportCSSHL(),
    keyword: keyword,
})

// 刷新索引
fetchPost("/api/ref/refreshBacklink", {
    id: this.blockId,
})
```

## refs 表结构 (数据库)

> 来源：`kernel/sql/block_ref_query.go` 的 `scanRefRows` 函数

| 字段 | 说明 |
|------|------|
| `ID` | 引用记录唯一 ID |
| `DefBlockID` | 被引用块 ID (目标块，即定义块) |
| `DefBlockParentID` | 被引用块的父块 ID |
| `DefBlockRootID` | 被引用块所属文档 ID |
| `DefBlockPath` | 被引用块路径 |
| `BlockID` | 引用块 ID (包含块引用的块) |
| `RootID` | 引用块所属文档 ID |
| `Box` | 笔记本 ID |
| `Path` | 路径 |
| `Content` | 锚文本内容 |
| `Markdown` | Markdown 内容 |
| `Type` | 引用类型 |

### 查询方向

```
文档A 中的块 X 引用了 文档B 中的块 Y

refs 表记录:
  - BlockID = X (引用块)
  - RootID = A (引用块所属文档)
  - DefBlockID = Y (被引用块)
  - DefBlockRootID = B (被引用块所属文档)

反向链接查询 (从 Y 的视角看)：
  SELECT * FROM refs WHERE def_block_id = 'Y'
  结果：找到 X

正向链接查询 (从 X/A 的视角看)：
  SELECT * FROM refs WHERE root_id = 'A'
  结果：找到所有 A 文档中的引用记录，包括目标 Y
```

## Dock 注册机制

### dock.factory.ts

```typescript
// 工厂函数
const initBacklink: ModelFactory = (app, tab, editor) => {
    return new Backlink({...});
};

// 类型到工厂的映射
const MODEL_FACTORIES: Record<string, ModelFactory> = {
    backlink: initBacklink,
    // ... 其他类型
};

// 统一创建入口
export const createModel = (options) => {
    const factory = MODEL_FACTORIES[options.type];
    if (factory) return factory(...);
    // 回退到插件
};
```

### 按钮配置

每个 Dock 类型需要在初始化时配置按钮，包括：
- `type`: 类型标识 (如 "backlink")
- `icon`: 图标 (如 "#iconLink")
- `title`: 显示标题
- `hotkey`: 快捷键
- `size`: 默认尺寸
