## 1. 基准测试代码模板

基准测试是性能优化的基础，本节提供不同场景下的基准测试代码模板。

### 1.1 测试数据生成函数

```go
// filter_benchmark_test.go
package av

import (
    "fmt"
    "math/rand"
    "testing"
    "time"
)

// generateTestRows 测试数据生成函数
func generateTestRows(count int) []*Row {
    rand.Seed(time.Now().UnixNano())
    rows := make([]*Row, count)
    for i := 0; i < count; i++ {
        rows[i] = &Row{
            ID: fmt.Sprintf("row-%d", i),
            Cells: map[string]*Cell{
                "status":     {Value: randomStatus()},
                "priority":   {Value: randomInt(1, 10)},
                "category":   {Value: randomCategory()},
                "tags":       {Value: randomTags()},
                "created_at": {Value: randomDate()},
            },
        }
    }
    return rows
}

// 辅助随机函数
func randomStatus() string {
    statuses := []string{"active", "inactive", "pending"}
    return statuses[rand.Intn(len(statuses))]
}

func randomInt(min, max int) int {
    return min + rand.Intn(max-min+1)
}

func randomCategory() string {
    categories := []string{"A", "B", "C", "D"}
    return categories[rand.Intn(len(categories))]
}

func randomTags() string {
    tags := []string{"important", "urgent", "normal", "test"}
    return tags[rand.Intn(len(tags))]
}

func randomDate() string {
    return "2024-01-01"
}
```

**使用说明**：
- 测试数据生成函数用于创建基准测试所需的数据
- 使用随机数据确保测试的真实性
- 可根据实际需求调整字段和数据类型

## 2. 单元测试代码模板

单元测试用于验证功能等价性，确保优化后的代码与原始实现完全一致。

### 2.1 表驱动测试模板

```go
// filter_test.go
package av

import (
    "testing"
    "github.com/stretchr/testify/assert"
)

// TestFilterRows_TableDriven 表驱动测试示例
func TestFilterRows_TableDriven(t *testing.T) {
    tests := []struct {
        name     string
        rows     []*Row
        filter   *Filter
        expected int
        wantErr  bool
    }{
        {
            name: "单条件过滤-等于",
            rows: generateTestRows(10),
            filter: &Filter{
                Conditions: []*FilterCondition{
                    {Column: "status", Operator: "=", Value: "active"},
                },
            },
            expected: 5,
            wantErr:  false,
        },
        {
            name: "多条件过滤-AND",
            rows: generateTestRows(10),
            filter: &Filter{
                Conditions: []*FilterCondition{
                    {Column: "status", Operator: "=", Value: "active"},
                    {Column: "priority", Operator: ">", Value: 5},
                },
            },
            expected: 3,
            wantErr:  false,
        },
        {
            name: "空条件",
            rows: generateTestRows(10),
            filter: &Filter{
                Conditions: []*FilterCondition{},
            },
            expected: 10,
            wantErr:  false,
        },
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            result := FilterRows(tt.rows, tt.filter)
            if tt.wantErr {
                assert.Error(t, err)
            } else {
                assert.NoError(t, err)
                assert.Equal(t, tt.expected, len(result))
            }
        })
    }
}
```

**使用说明**：
- 表驱动测试便于添加新的测试用例
- 每个测试用例包含名称、输入、期望输出和错误标志
- 使用 `t.Run` 创建子测试，便于定位失败的用例

```go
// TestFilterRows_Equivalence 验证优化前后功能等价性
func TestFilterRows_Equivalence(t *testing.T) {
    testCases := []struct {
        name   string
        rows   []*Row
        filter *Filter
    }{
        {
            name:   "简单过滤",
            rows:   generateTestRows(1000),
            filter: &Filter{Conditions: []*FilterCondition{{Column: "status", Operator: "=", Value: "active"}}},
        },
        {
            name:   "复杂过滤",
            rows:   generateTestRows(1000),
            filter: &Filter{
                Conditions: []*FilterCondition{
                    {Column: "status", Operator: "=", Value: "active"},
                    {Column: "priority", Operator: ">", Value: 5},
                    {Column: "category", Operator: "in", Value: []string{"A", "B"}},
                },
            },
        },
    }
    
    for _, tc := range testCases {
        t.Run(tc.name, func(t *testing.T) {
            // 调用原始实现
            resultOriginal := FilterRowsOriginal(tc.rows, tc.filter)
            
            // 调用优化后的实现
            resultOptimized := FilterRows(tc.rows, tc.filter)
            
            // 验证结果完全一致
            assert.Equal(t, len(resultOriginal), len(resultOptimized), "结果数量应该相同")
            
            // 验证每一行的ID都相同
            for i := range resultOriginal {
                assert.Equal(t, resultOriginal[i].ID, resultOptimized[i].ID,
                    "第%d行的ID应该相同", i)
            }
        })
    }
}
```

**使用说明**：
- 对比优化前后的实现结果
- 确保功能完全等价
- 在优化的每个阶段都应运行此测试

## 3. 边界条件测试案例库

边界条件测试确保代码在极端情况下也能正确运行，避免panic和错误。

### 3.1 空输入测试

```go
// filter_boundary_test.go
package av

import (
    "testing"
    "github.com/stretchr/testify/assert"
)

// TestFilterRows_EmptyInput 测试空输入
func TestFilterRows_EmptyInput(t *testing.T) {
    tests := []struct {
        name   string
        rows   []*Row
        filter *Filter
    }{
        {
            name:   "空行切片",
            rows:   []*Row{},
            filter: &Filter{Conditions: []*FilterCondition{{Column: "status", Operator: "=", Value: "active"}}},
        },
        {
            name:   "nil行切片",
            rows:   nil,
            filter: &Filter{Conditions: []*FilterCondition{{Column: "status", Operator: "=", Value: "active"}}},
        },
        {
            name:   "空过滤条件",
            rows:   generateTestRows(10),
            filter: &Filter{Conditions: []*FilterCondition{}},
        },
        {
            name:   "nil过滤器",
            rows:   generateTestRows(10),
            filter: nil,
        },
    }
    
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            // 不应该panic
            assert.NotPanics(t, func() {
                result := FilterRows(tt.rows, tt.filter)
                assert.NotNil(t, result)
            })
        })
    }
}
```

**使用说明**：
- 测试空切片、nil值等边界情况
- 确保代码不会panic
- 验证空输入的处理逻辑

## 4. 性能分析代码模板

性能分析帮助识别性能瓶颈，本节提供CPU、内存和并发性能分析的代码模板。

### 4.1 CPU性能分析

```go
// filter_profile_test.go
package av

import (
    "os"
    "runtime/pprof"
    "testing"
)

// TestFilterRows_CPUProfile CPU性能分析
func TestFilterRows_CPUProfile(t *testing.T) {
    // 创建CPU profile文件
    cpuProfile, err := os.Create("cpu.prof")
    if err != nil {
        t.Fatal(err)
    }
    defer cpuProfile.Close()
    
    // 启动CPU性能分析
    if err := pprof.StartCPUProfile(cpuProfile); err != nil {
        t.Fatal(err)
    }
    defer pprof.StopCPUProfile()
    
    // 运行测试
    rows := generateTestRows(10000)
    filter := &Filter{
        Conditions: []*FilterCondition{
            {Column: "status", Operator: "=", Value: "active"},
        },
    }
    
    for i := 0; i < 1000; i++ {
        FilterRows(rows, filter)
    }
}
```

**使用说明**：
- 生成CPU性能分析文件 `cpu.prof`
- 使用 `go tool pprof cpu.prof` 分析
- 识别CPU热点函数
- 优化CPU密集型操作

**分析命令**：
```bash
# 分析CPU profile
go tool pprof cpu.prof

# 启动web界面
go tool pprof -http=:8080 cpu.prof

# 生成火焰图
go tool pprof -svg cpu.prof > cpu_profile.svg
```
