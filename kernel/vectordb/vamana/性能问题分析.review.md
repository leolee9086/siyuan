## 🔴 严重问题

### 1. NeighborPriorityQueue.Insert 复杂度灾难

**位置**: `types.go:194-232`

```go
func (pq *NeighborPriorityQueue) Insert(n Neighbor) {
    // 问题1: O(n)线性扫描去重
    for i := range pq.data {
        if pq.data[i].ID == n.ID {
            if n.Distance < pq.data[i].Distance {
                pq.data[i].Distance = n.Distance
                // 问题2: 距离更新后触发全量排序 O(n log n)
                sort.Slice(pq.data, func(i, j int) bool {
                    return pq.data[i].Distance < pq.data[j].Distance
                })
            }
            return
        }
    }
    // ...
}
```

**问题分析**:
- 每次Insert都做O(n)线性扫描检查重复
- 距离更新时触发完整的O(n log n)排序
- 典型搜索中Insert被调用数百次 → O(n² log n) 总复杂度

**解决方案**: 使用堆(heap)结构 + map去重，或维护增量排序

```go
// 修复版本
type NeighborPriorityQueue struct {
    data     []Neighbor
    capacity int
    idSet    map[uint32]int  // ID -> 在data中的位置
    minUnvisitedIdx int       // 最小未访问索引
}

func (pq *NeighborPriorityQueue) Insert(n Neighbor) {
    if pos, exists := pq.idSet[n.ID]; exists {
        if n.Distance < pq.data[pos].Distance {
            // 仅调整单个元素位置，不重排全部
            pq.data[pos].Distance = n.Distance
            pq.siftUp(pos)  // O(log n)
        }
        return
    }
    // 二分插入 O(n)，但没有排序开销
    pq.insertSorted(n)
    pq.idSet[n.ID] = len(pq.data) - 1
}
```

### 2. HasUnvisited 每次O(n)遍历

**位置**: `types.go:235-241`

```go
func (pq *NeighborPriorityQueue) HasUnvisited() bool {
    for i := range pq.visited {
        if !pq.visited[i] {
            return true
        }
    }
    return false
}
```

**问题分析**:
- 每次循环都从头遍历visited数组
- greedySearch中被调用 O(搜索宽度) 次
- 实际上前面的元素大概率已访问，从头检查浪费

**解决方案**: 维护第一个未访问索引

```go
type NeighborPriorityQueue struct {
    // ...
    minUnvisitedIdx int  // 第一个未访问的索引
}

func (pq *NeighborPriorityQueue) HasUnvisited() bool {
    return pq.minUnvisitedIdx < len(pq.data)  // O(1)
}

func (pq *NeighborPriorityQueue) PopClosestUnvisited() (Neighbor, bool) {
    if pq.minUnvisitedIdx >= len(pq.data) {
        return Neighbor{}, false
    }
    n := pq.data[pq.minUnvisitedIdx]
    pq.visited[pq.minUnvisitedIdx] = true
    pq.minUnvisitedIdx++  // 下次直接从这里开始
    return n, true
}
```

### 3. greedySearch 频繁加锁

**位置**: `index.go:226-228`

```go
for scratch.Best.HasUnvisited() {
    // ...
    idx.mu.RLock()                          // 每次循环加锁
    neighbors := idx.neighbors[closest.ID]
    idx.mu.RUnlock()                        // 每次循环解锁
    // ...
}
```

**问题分析**:
- 搜索期间邻居结构不会变化（只读操作）
- 每次循环加解锁有开销
- 锁竞争在并发查询时更严重

**解决方案**: 搜索前一次性加读锁，搜索完解锁

```go
func (idx *VamanaIndex) greedySearch(...) []Neighbor {
    idx.mu.RLock()
    defer idx.mu.RUnlock()  // 整个搜索期间持锁
    
    for scratch.Best.HasUnvisited() {
        // 不需要再加锁
        neighbors := idx.neighbors[closest.ID]
        // ...
    }
}
```

### 4. robustPrune中O(N²)距离计算

**位置**: `index.go:316`

```go
for lastChecked[i] < len(resultPos) {
    // ...
    distCN := idx.distance(cand.ID, selectedID)  // 💥 每对都计算
    // ...
}
```

**问题分析**:
- 对每对(候选, 已选)计算距离
- 候选数量可达MaxOcclusionSize (750)
- 最坏情况: O(候选数 × 结果数 × 维度) = O(750 × 64 × 128)

**解决方案**: 预计算距离矩阵或使用向量范数估计

```go
// 方案1: 预计算距离矩阵 (空间换时间)
func (idx *VamanaIndex) robustPruneOptimized(...) []uint32 {
    n := len(candidates)
    // 预计算所有候选之间的距离 O(n²)，但只算一次
    distMatrix := make([][]float32, n)
    for i := 0; i < n; i++ {
        distMatrix[i] = make([]float32, n)
        for j := i + 1; j < n; j++ {
            d := idx.distance(candidates[i].ID, candidates[j].ID)
            distMatrix[i][j] = d
            distMatrix[j][i] = d
        }
    }
    // 后续使用 distMatrix[i][j] 查表
}

// 方案2: 使用范数估计 (近似但更快)
func (idx *VamanaIndex) fastDistance(id1, id2 uint32) float32 {
    // ||a-b||² = ||a||² + ||b||² - 2<a,b>
    // 使用预计算的范数
    return idx.normSquares[id1] + idx.normSquares[id2] - 
           2*dotProduct(idx.vectors[id1], idx.vectors[id2])
}
```

| 问题 | 复杂度影响 | 修复优先级 |
|------|-----------|------------|
| Insert O(n)去重 + 重排序 | O(n² log n) → O(n log n) | **P0** |
| HasUnvisited O(n)遍历 | O(L²) → O(L) | **P0** |

### 第一步: 修复NeighborPriorityQueue (最关键)

```go
type NeighborPriorityQueue struct {
    data            []Neighbor
    capacity        int
    idToPos         map[uint32]int  // 新增: ID到位置的映射
    minUnvisitedIdx int              // 新增: 第一个未访问索引
}

func (pq *NeighborPriorityQueue) Reset() {
    pq.data = pq.data[:0]
    for k := range pq.idToPos {
        delete(pq.idToPos, k)  // 或重新make
    }
    pq.minUnvisitedIdx = 0
}

func (pq *NeighborPriorityQueue) Insert(n Neighbor) {
    // O(1) 检查重复
    if pos, exists := pq.idToPos[n.ID]; exists {
        if n.Distance < pq.data[pos].Distance {
            pq.data[pos].Distance = n.Distance
            // 只需要将这个元素向前移动
            for pos > 0 && pq.data[pos].Distance < pq.data[pos-1].Distance {
                pq.data[pos], pq.data[pos-1] = pq.data[pos-1], pq.data[pos]
                pq.idToPos[pq.data[pos].ID] = pos
                pq.idToPos[pq.data[pos-1].ID] = pos - 1
                pos--
            }
        }
        return
    }
    
    // 容量满时淘汰最差的
    if len(pq.data) >= pq.capacity {
        if n.Distance >= pq.data[len(pq.data)-1].Distance {
            return
        }
        evicted := pq.data[len(pq.data)-1]
        delete(pq.idToPos, evicted.ID)
        pq.data = pq.data[:len(pq.data)-1]
    }
    
    // 二分插入
    pos := sort.Search(len(pq.data), func(i int) bool {
        return pq.data[i].Distance > n.Distance
    })
    
    pq.data = append(pq.data, Neighbor{})
    copy(pq.data[pos+1:], pq.data[pos:])
    pq.data[pos] = n
    
    // 更新映射
    for i := pos; i < len(pq.data); i++ {
        pq.idToPos[pq.data[i].ID] = i
    }
}

func (pq *NeighborPriorityQueue) HasUnvisited() bool {
    return pq.minUnvisitedIdx < len(pq.data)
}

func (pq *NeighborPriorityQueue) PopClosestUnvisited() (Neighbor, bool) {
    if pq.minUnvisitedIdx >= len(pq.data) {
        return Neighbor{}, false
    }
    n := pq.data[pq.minUnvisitedIdx]
    pq.minUnvisitedIdx++
    return n, true
}
```
