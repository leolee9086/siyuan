## 问题 2：任务覆盖时旧 goroutine 未停止

**位置**: [`cronjob.go`](file:///d:/dev/siyuan-note/kernel/cronjob/cronjob.go#L281-L287)

```go
m.Lock.Lock()
m.Tasks[docID] = task  // ⚠️ 覆盖了 map，但旧 goroutine 仍在运行
delete(m.LoadErrors, docID)
m.Lock.Unlock()

go m.RunTaskLoop(task)  // 启动新 goroutine
```

**问题**: 
- 当同一文档被重新编译时，`m.Tasks[docID]` 被新任务覆盖
- 但旧任务的 `RunTaskLoop` goroutine **仍在运行**
- 旧 goroutine 持有旧的 `task.StopChan`，而 `m.Tasks[docID]` 已指向新 task
- 结果：**两个版本的任务同时执行**

**修复建议**:

在启动新任务之前，先停止旧任务：

```go
// CompileAndStartTask 编译文档中的代码并启动任务
func (m *Manager) CompileAndStartTask(docID string) error {
    // ... 编译代码 ...
    
    // ✅ 先停止旧任务（如果存在）
    m.Lock.Lock()
    if oldTask, exists := m.Tasks[docID]; exists {
        close(oldTask.StopChan)  // 通知旧 goroutine 退出
    }
    m.Tasks[docID] = task
    delete(m.LoadErrors, docID)
    m.Lock.Unlock()

    // 启动新任务
    go m.RunTaskLoop(task)
    return nil
}
```
