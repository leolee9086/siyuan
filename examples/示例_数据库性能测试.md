# 数据库性能测试插件

这是一个笔记内插件示例，用于测试数据库视图的性能，演示如何：
1. 查询工作空间中的段落块
2. 将块批量添加到数据库视图
3. 创建多种类型的列（文本、数字、日期、选择、模板列）
4. 测试数据库渲染操作的性能

> ⚠️ **注意**：此脚本会创建大量测试数据，建议在测试环境中使用。

## 插件配置

设置以下文档属性后，此文档即可作为笔记内插件运行：

- `ext-type`: `plugin`  
- `ext-lang`: `js`

## 功能说明

- 🔍 查询工作空间中的段落块
- 📥 批量添加块到指定数据库
- 📊 创建多种类型的测试列
- ⏱️ 测量并显示性能数据
- 📋 结果以对话框形式展示

## 插件代码

```js ext-type="plugin" ext-lang="js"
// 导入思源插件API
import { Plugin, showMessage, Dialog } from "siyuan";

/**
 * 数据库性能测试插件
 * 测试数据库视图的过滤性能，创建多种类型的列并进行性能测量
 */
export default class DatabasePerfTest extends Plugin {
    // ========== 用户配置 ==========
    
    /** 要添加到数据库的块数量限制 */
    blockLimit = 500;
    
    /** 是否创建测试列 */
    createTestColumns = true;
    
    /** 性能测试重复次数 */
    benchmarkIterations = 5;

    /**
     * 插件加载时调用
     */
    async onload() {
        console.log("[DatabasePerfTest] 插件已加载");
        
        // 添加顶栏按钮
        this.addTopBar({
            icon: "iconDatabase",
            title: "数据库性能测试",
            callback: () => this.showConfigDialog()
        });

        showMessage("数据库性能测试插件已启用 🔬", 2000);
    }

    /**
     * 插件卸载时调用
     */
    async onunload() {
        console.log("[DatabasePerfTest] 插件已卸载");
        showMessage("数据库性能测试插件已禁用", 2000);
    }

    /**
     * 显示配置对话框
     */
    showConfigDialog() {
        const dialog = new Dialog({
            title: "🔬 数据库性能测试",
            content: `
                <div class="b3-dialog__content" style="padding: 16px;">
                    <div class="fn__flex-column" style="gap: 16px;">
                        <div class="fn__flex-column" style="gap: 8px;">
                            <label class="b3-label">
                                <span>数据库视图 ID (avID)</span>
                                <input id="perftest-avid" class="b3-text-field fn__block" 
                                    placeholder="请输入要测试的数据库视图 ID" />
                            </label>
                            <div class="b3-label__text" style="font-size: 12px; color: var(--b3-theme-on-surface-light);">
                                提示：在数据库块上右键 → 复制 → 复制块 ID，或查看块属性中的 data-av-id
                            </div>
                        </div>
                        
                        <div class="fn__flex-column" style="gap: 8px;">
                            <label class="b3-label">
                                <span>添加块数量</span>
                                <input id="perftest-limit" class="b3-text-field fn__block" 
                                    type="number" value="500" min="10" max="2000" />
                            </label>
                        </div>
                        
                        <div class="fn__flex-column" style="gap: 8px;">
                            <label class="b3-label">
                                <span>性能测试迭代次数</span>
                                <input id="perftest-iterations" class="b3-text-field fn__block" 
                                    type="number" value="5" min="1" max="20" />
                            </label>
                        </div>
                        
                        <div class="fn__flex" style="gap: 16px;">
                            <label class="fn__flex" style="align-items: center; gap: 8px;">
                                <input id="perftest-create-cols" type="checkbox" class="b3-switch" checked />
                                <span>创建测试列</span>
                            </label>
                        </div>
                    </div>
                </div>
            `,
            width: "520px",
            height: "auto"
        });

        // 添加底部按钮
        const btnsContainer = document.createElement("div");
        btnsContainer.className = "b3-dialog__action";
        btnsContainer.innerHTML = `
            <button class="b3-button b3-button--cancel">取消</button>
            <button class="b3-button b3-button--text" id="perftest-run">
                <svg class="b3-button__icon"><use xlink:href="#iconPlay"></use></svg>
                开始测试
            </button>
        `;
        dialog.element.querySelector(".b3-dialog__container").appendChild(btnsContainer);

        // 绑定事件
        btnsContainer.querySelector(".b3-button--cancel").addEventListener("click", () => {
            dialog.destroy();
        });

        btnsContainer.querySelector("#perftest-run").addEventListener("click", async () => {
            const avID = dialog.element.querySelector("#perftest-avid").value.trim();
            const blockLimit = parseInt(dialog.element.querySelector("#perftest-limit").value) || 500;
            const iterations = parseInt(dialog.element.querySelector("#perftest-iterations").value) || 5;
            const createCols = dialog.element.querySelector("#perftest-create-cols").checked;

            if (!avID) {
                showMessage("请输入数据库视图 ID", 3000, "error");
                return;
            }

            dialog.destroy();
            
            // 更新配置
            this.blockLimit = blockLimit;
            this.benchmarkIterations = iterations;
            this.createTestColumns = createCols;
            
            // 运行测试
            await this.runTest(avID);
        });
    }

    /**
     * 运行性能测试
     * @param {string} avID - 数据库视图 ID
     */
    async runTest(avID) {
        const results = {
            startTime: new Date().toLocaleString(),
            avID: avID,
            steps: [],
            errors: []
        };

        showMessage("🔬 数据库性能测试开始...", 2000);
        console.log("========== 数据库性能测试开始 ==========");

        try {
            // 步骤 1: 查询段落块
            showMessage("步骤 1/4: 查询段落块...", 2000);
            const queryStart = performance.now();
            const blocks = await this.queryParagraphBlocks();
            const queryTime = performance.now() - queryStart;
            
            results.steps.push({
                name: "查询段落块",
                count: blocks.length,
                time: queryTime.toFixed(2) + "ms"
            });
            console.log(`[DatabasePerfTest] 查询到 ${blocks.length} 个段落块，耗时 ${queryTime.toFixed(2)}ms`);

            if (blocks.length === 0) {
                throw new Error("没有找到可用的段落块");
            }

            // 步骤 2: 添加块到数据库
            showMessage("步骤 2/4: 添加块到数据库...", 2000);
            const addStart = performance.now();
            const addedCount = await this.addBlocksToDatabase(avID, blocks);
            const addTime = performance.now() - addStart;
            
            results.steps.push({
                name: "添加块到数据库",
                count: addedCount,
                time: addTime.toFixed(2) + "ms"
            });
            console.log(`[DatabasePerfTest] 成功添加 ${addedCount} 个块，耗时 ${addTime.toFixed(2)}ms`);

            // 步骤 3: 创建测试列
            if (this.createTestColumns) {
                showMessage("步骤 3/4: 创建测试列...", 2000);
                const colStart = performance.now();
                const colResults = await this.createColumns(avID);
                const colTime = performance.now() - colStart;
                
                results.steps.push({
                    name: "创建测试列",
                    count: colResults.success,
                    time: colTime.toFixed(2) + "ms",
                    details: colResults.columns
                });
                console.log(`[DatabasePerfTest] 创建了 ${colResults.success} 个测试列，耗时 ${colTime.toFixed(2)}ms`);

                // 步骤 3.5: 填充列数据
                if (colResults.success > 0) {
                    showMessage("步骤 3.5/4: 填充列数据...", 2000);
                    const popStart = performance.now();
                    const popCount = await this.populateData(avID, blocks, colResults.columns);
                    const popTime = performance.now() - popStart;

                    results.steps.push({
                        name: "填充列数据",
                        count: popCount,
                        time: popTime.toFixed(2) + "ms"
                    });
                    console.log(`[DatabasePerfTest] 填充了 ${popCount} 条数据，耗时 ${popTime.toFixed(2)}ms`);
                }
            }

            // 步骤 4: 性能测试
            showMessage("步骤 4/4: 执行渲染性能测试...", 2000);
            const perfResults = await this.runPerformanceTest(avID);
            results.steps.push({
                name: "渲染性能测试",
                details: perfResults
            });

            // 显示结果
            this.showResults(results);

        } catch (error) {
            console.error("[DatabasePerfTest] 测试失败:", error);
            results.errors.push(error.message);
            showMessage(`测试失败: ${error.message}`, 5000, "error");
            this.showResults(results);
        }

        console.log("========== 数据库性能测试完成 ==========");
    }

    /**
     * 查询段落块
     * @returns {Promise<string[]>} 块 ID 数组
     */
    async queryParagraphBlocks() {
        const stmt = `SELECT id FROM blocks WHERE type = 'p' AND length > 10 LIMIT ${this.blockLimit}`;
        
        const response = await fetch("/api/query/sql", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ stmt })
        });

        const result = await response.json();
        if (result.code !== 0) {
            throw new Error(`查询失败: ${result.msg}`);
        }

        return (result.data || []).map(row => row.id);
    }

    /**
     * 将块添加到数据库
     * @param {string} avID - 数据库视图 ID
     * @param {string[]} blockIDs - 块 ID 数组
     * @returns {Promise<number>} 成功添加的数量
     */
    async addBlocksToDatabase(avID, blockIDs) {
        let addedCount = 0;
        const batchSize = 50;

        for (let i = 0; i < blockIDs.length; i += batchSize) {
            const batch = blockIDs.slice(i, i + batchSize);
            const srcs = batch.map(id => ({
                id: id,
                isDetached: false
            }));

            try {
                const response = await fetch("/api/av/addAttributeViewBlocks", {
                    method: "POST",
                    headers: { "Content-Type": "application/json" },
                    body: JSON.stringify({ avID, srcs })
                });

                const result = await response.json();
                if (result.code === 0) {
                    addedCount += batch.length;
                } else {
                    console.warn(`[DatabasePerfTest] 批次 ${i}-${i + batch.length} 添加失败:`, result.msg);
                }
            } catch (error) {
                console.warn(`[DatabasePerfTest] 批次 ${i}-${i + batch.length} 添加出错:`, error);
            }

            // 避免请求过快
            await this.sleep(100);
        }

        return addedCount;
    }

    /**
     * 创建测试列
     * @param {string} avID - 数据库视图 ID
     * @returns {Promise<{success: number, columns: object[]}>}
     */
    async createColumns(avID) {
        const columns = [
            { keyID: "test_text_col", keyName: "测试文本列", keyType: "text" },
            { keyID: "test_number_col", keyName: "测试数字列", keyType: "number" },
            { keyID: "test_date_col", keyName: "测试日期列", keyType: "date" },
            { keyID: "test_select_col", keyName: "测试选择列", keyType: "select" },
            { keyID: "test_template_col", keyName: "测试模板列", keyType: "template" }
        ];

        const results = { success: 0, columns: [] };

        for (const col of columns) {
            try {
                const response = await fetch("/api/av/addAttributeViewKey", {
                    method: "POST",
                    headers: { "Content-Type": "application/json" },
                    body: JSON.stringify({
                        avID,
                        keyID: col.keyID,
                        keyName: col.keyName,
                        keyType: col.keyType,
                        keyIcon: "",
                        previousKeyID: ""
                    })
                });

                const result = await response.json();
                if (result.code === 0) {
                    results.success++;
                    results.columns.push({ ...col, status: "success" });
                    console.log(`[DatabasePerfTest] 创建列成功: ${col.keyName} (${col.keyType})`);
                } else {
                    results.columns.push({ ...col, status: "failed", error: result.msg });
                    console.warn(`[DatabasePerfTest] 创建列 ${col.keyName} 失败:`, result.msg);
                }
            } catch (error) {
                results.columns.push({ ...col, status: "error", error: error.message });
                console.warn(`[DatabasePerfTest] 创建列 ${col.keyName} 出错:`, error);
            }

            await this.sleep(50);
        }

        return results;
    }

    /**
     * 执行渲染性能测试
     * @param {string} avID - 数据库视图 ID
     * @returns {Promise<object[]>}
     */
    async runPerformanceTest(avID) {
        const pageSizes = [10, 50, 100, 200];
        const results = [];

        console.log("[DatabasePerfTest] --- 渲染性能测试 ---");

        for (const pageSize of pageSizes) {
            const times = [];

            for (let i = 0; i < this.benchmarkIterations; i++) {
                const start = performance.now();

                try {
                    const response = await fetch("/api/av/renderAttributeView", {
                        method: "POST",
                        headers: { "Content-Type": "application/json" },
                        body: JSON.stringify({
                            id: avID,
                            page: 1,
                            pageSize: pageSize
                        })
                    });

                    const result = await response.json();
                    const duration = performance.now() - start;

                    if (result.code === 0) {
                        times.push(duration);
                    } else {
                        console.warn(`[DatabasePerfTest] 渲染失败 (pageSize=${pageSize}):`, result.msg);
                    }
                } catch (error) {
                    console.warn(`[DatabasePerfTest] 渲染出错 (pageSize=${pageSize}):`, error);
                }
            }

            if (times.length > 0) {
                const avg = times.reduce((a, b) => a + b, 0) / times.length;
                const min = Math.min(...times);
                const max = Math.max(...times);

                results.push({
                    pageSize,
                    iterations: times.length,
                    avgTime: avg.toFixed(2) + "ms",
                    minTime: min.toFixed(2) + "ms",
                    maxTime: max.toFixed(2) + "ms"
                });

                console.log(`[DatabasePerfTest] pageSize=${pageSize}: 平均 ${avg.toFixed(2)}ms (${times.length} 次)`);
            }
        }

        console.log("[DatabasePerfTest] --- 性能测试完成 ---");
        return results;
    }

    /**
     * 显示测试结果对话框
     * @param {object} results - 测试结果

    showResults(results) {
        let stepsHtml = results.steps.map(step => {

                detailsHtml = `

        }).join("");

        let errorsHtml = "";

            errorsHtml = `
                <div style="padding: 8px; background: var(--b3-card-error-background); border-radius: 4px; margin-top: 8px;">
                    <strong style="color: var(--b3-card-error-color);">错误:</strong>
                    <ul style="margin: 4px 0 0 16px; color: var(--b3-card-error-color);">
                        ${results.errors.map(e => `<li>${e}</li>`).join("")}
                    </ul>
                </div>
            `;
        }

        const dialog = new Dialog({
            title: "📊 数据库性能测试结果",
            content: `
                <div class="b3-dialog__content" style="padding: 16px; max-height: 70vh; overflow-y: auto;">
                    <div style="margin-bottom: 16px; padding: 8px; background: var(--b3-theme-surface-lighter); border-radius: 4px;">
                        <div><strong>测试时间:</strong> ${results.startTime}</div>
                        <div><strong>数据库 ID:</strong> <code>${results.avID}</code></div>
                    </div>
                    
                    <h4 style="margin: 0 0 8px 0;">测试步骤</h4>
                    ${stepsHtml}
                    ${errorsHtml}
                </div>
            `,
            width: "600px",
            height: "auto"
        });

        // 添加关闭按钮
        const btnsContainer = document.createElement("div");
        btnsContainer.className = "b3-dialog__action";
        btnsContainer.innerHTML = `<button class="b3-button b3-button--text">关闭</button>`;
        dialog.element.querySelector(".b3-dialog__container").appendChild(btnsContainer);
        btnsContainer.querySelector("button").addEventListener("click", () => dialog.destroy());
    }

    /**
     * 延时函数
     * @param {number} ms - 毫秒数
     */
    sleep(ms) {
        return new Promise(resolve => setTimeout(resolve, ms));
    }

    /**
     * 填充列数据
     * @param {string} avID 
     * @param {string[]} blockIDs 
     * @param {any[]} columns 
     */
    async populateData(avID, blockIDs, columns) {
        let populatedCount = 0;
        const batchSize = 50;
        const validColumns = columns.filter(col => col.status === "success");

        if (validColumns.length === 0) return 0;

        console.log(`[DatabasePerfTest] 开始填充数据，共 ${blockIDs.length} 个块，${validColumns.length} 个列`);

        for (let i = 0; i < blockIDs.length; i += batchSize) {
            const batchBlocks = blockIDs.slice(i, i + batchSize);
            const values = [];

            for (const blockID of batchBlocks) {
                for (const col of validColumns) {
                    const value = this.createCellValue(col.keyType, i);
                    if (value) {
                        values.push({
                            blockID: blockID,
                            keyID: col.keyID,
                            value: value
                        });
                    }
                }
            }

            if (values.length > 0) {
                try {
                    // 使用 batchSetAttributeViewBlockAttrs 批量设置
                    const response = await fetch("/api/av/batchSetAttributeViewBlockAttrs", {
                        method: "POST",
                        headers: { "Content-Type": "application/json" },
                        body: JSON.stringify({
                            avID,
                            values
                        })
                    });
                    
                    const result = await response.json();
                    if (result.code === 0) {
                        populatedCount += batchBlocks.length * validColumns.length;
                    } else {
                        console.warn(`[DatabasePerfTest] 数据填充失败 (batch ${i}):`, result.msg);
                    }
                } catch (e) {
                    console.error(`[DatabasePerfTest] 数据填充出错 (batch ${i}):`, e);
                }
            }

             // 避免请求过快
             await this.sleep(100);
        }

        return populatedCount;
    }

    /**
     * 创建单元格值
     * @param {string} type 
     * @param {number} seed 
     */
    createCellValue(type, seed) {
        const rand = Math.random();
        
        switch (type) {
            case "text":
                return {
                    type: "text",
                    text: {
                        content: `测试文本 ${Math.floor(rand * 1000)}`
                    }
                };
            case "number":
                const num = Math.floor(rand * 10000);
                return {
                    type: "number",
                    number: {
                        content: num,
                        isNotEmpty: true,
                        formattedContent: num.toString()
                    }
                };
            case "date":
                // 随机生成最近 30 天的日期
                const date = new Date();
                date.setDate(date.getDate() - Math.floor(rand * 30));
                return {
                    type: "date",
                    date: {
                        content: date.getTime(),
                        isNotEmpty: true,
                        hasEndDate: false,
                        isNotTime: true,
                        formattedContent: ""
                    }
                };
            case "select":
                return {
                    type: "select",
                    mSelect: [{
                        content: ["选项A", "选项B", "选项C", "选项D"][Math.floor(rand * 4)],
                        color: "1"
                    }]
                };
            case "template":
                // 模板列通常是计算得出的，但也支持手动设置值（虽然会被重算覆盖，但用于测试初始渲染性能是有意义的）
                return {
                    type: "template",
                    template: {
                        content: `Tpl: ${Math.floor(rand * 100)}`
                    }
                };
            default:
                return null;
        }
    }
}
```

## 使用说明

### 1. 设置属性

打开此文档，按 `Ctrl+Shift+A` 或点击右上角 `···` → `属性`，添加自定义属性：
- `ext-type` = `plugin`
- `ext-lang` = `js`

### 2. 启用插件

- 右键点击文档树中的此文档
- 选择"注册为笔记内插件"
- 插件将自动加载，顶栏会出现数据库图标按钮

### 3. 获取数据库视图 ID

1. 打开包含数据库的文档
2. 在数据库块上右键 → 复制 → 复制块 ID
3. 或者查看数据库块的属性，找到 `data-av-id` 属性

### 4. 运行测试

1. 点击顶栏的数据库图标按钮
2. 在弹出的配置对话框中：
   - 输入数据库视图 ID
   - 设置要添加的块数量（默认 500）
   - 设置性能测试迭代次数（默认 5）
   - 选择是否创建测试列
3. 点击"开始测试"按钮

### 5. 查看结果

测试完成后会弹出结果对话框，显示：
- 各步骤的执行时间
- 添加的块数量
- 创建的列信息
- 不同 pageSize 下的渲染性能数据

## 测试列说明

脚本会创建以下测试列：

| 列名 | 类型 | 用途 |
|------|------|------|
| 测试文本列 | text | 基础文本过滤测试 |
| 测试数字列 | number | 数值比较过滤测试 |
| 测试日期列 | date | 日期范围过滤测试 |
| 测试选择列 | select | 枚举值过滤测试 |
| 测试模板列 | template | 计算列性能测试 |

## 性能指标

脚本会输出以下性能指标：

1. **查询耗时**：查询段落块的时间
2. **批量添加耗时**：添加块到数据库的时间
3. **列创建耗时**：创建测试列的时间
4. **渲染耗时**：不同 pageSize 下的平均/最小/最大渲染时间

## 注意事项

1. **测试数据量**：默认添加 500 个块，可根据需要调整（10-2000）
2. **重复执行**：多次执行会重复添加块，建议测试前清空数据库
3. **性能影响**：大量数据可能影响思源笔记的响应速度
4. **日志查看**：详细日志会输出到浏览器控制台（F12）

3. 添加并发请求测试
