# 示例：文档字数统计插件

这是一个笔记内插件示例，演示如何为思源笔记添加一个实时字数统计面板。当激活后，会在状态栏显示当前文档的字数、段落数等信息。

## 插件配置

设置以下文档属性后，此文档即可作为笔记内插件运行：

- `ext-type`: `plugin`  
- `ext-lang`: `js`

## 功能说明

- 🔢 实时统计当前文档字数、词数、段落数
- 📊 在状态栏显示统计信息
- 🔄 自动更新（文档内容变化时）
- ⚙️ 点击状态栏图标可查看详细统计

## 插件代码

```javascript
// 导入思源插件API
import { Plugin, showMessage, confirm } from "siyuan";

/**
 * 文档统计插件
 * 在状态栏显示当前文档的字数统计信息
 */
export default class WordCountPlugin extends Plugin {
    // 状态栏元素
    statusBarElement = null;
    // 定时器ID
    updateTimer = null;
    // 上次统计的文档ID
    lastDocId = null;

    /**
     * 插件加载时调用
     */
    async onload() {
        console.log("[WordCount] 插件已加载");
        
        // 添加状态栏按钮
        this.statusBarElement = this.addStatusBar({
            element: this.createStatusBarElement(),
            position: "right"
        });

        // 监听文档切换事件
        this.eventBus.on("switch-protyle", this.handleDocSwitch.bind(this));
        
        // 监听文档内容变化
        this.eventBus.on("loaded-protyle-static", this.handleDocLoaded.bind(this));
        
        // 启动定时更新（每5秒更新一次统计）
        this.updateTimer = setInterval(() => {
            this.updateStatistics();
        }, 5000);

        showMessage("字数统计插件已启用 📊", 2000);
    }

    /**
     * 插件卸载时调用
     */
    async onunload() {
        console.log("[WordCount] 插件已卸载");
        
        // 清除定时器
        if (this.updateTimer) {
            clearInterval(this.updateTimer);
            this.updateTimer = null;
        }
        
        showMessage("字数统计插件已禁用", 2000);
    }

    /**
     * 创建状态栏元素
     */
    createStatusBarElement() {
        const container = document.createElement("div");
        container.className = "wordcount-status";
        container.style.cssText = `
            display: flex;
            align-items: center;
            gap: 8px;
            cursor: pointer;
            padding: 0 8px;
            font-size: 12px;
            color: var(--b3-theme-on-surface);
        `;
        container.innerHTML = `
            <svg class="b3-menu__icon" style="width: 14px; height: 14px;">
                <use xlink:href="#iconFile"></use>
            </svg>
            <span class="wordcount-text">统计中...</span>
        `;
        
        // 点击显示详细统计
        container.addEventListener("click", () => {
            this.showDetailedStats();
        });
        
        return container;
    }

    /**
     * 处理文档切换
     */
    handleDocSwitch(event) {
        const protyle = event?.detail?.protyle;
        if (protyle?.block?.rootID) {
            this.lastDocId = protyle.block.rootID;
            this.updateStatistics();
        }
    }

    /**
     * 处理文档加载完成
     */
    handleDocLoaded(event) {
        setTimeout(() => {
            this.updateStatistics();
        }, 500);
    }

    /**
     * 更新统计信息
     */
    async updateStatistics() {
        // 获取当前打开的编辑器
        const protyle = this.getCurrentProtyle();
        if (!protyle) {
            this.updateStatusBar("未打开文档");
            return;
        }

        const rootId = protyle.block?.rootID;
        if (!rootId) {
            this.updateStatusBar("无文档");
            return;
        }

        try {
            // 使用内核API获取文档内容
            const response = await fetch("/api/export/exportMdContent", {
                method: "POST",
                headers: { "Content-Type": "application/json" },
                body: JSON.stringify({ id: rootId })
            });
            
            const result = await response.json();
            if (result.code === 0 && result.data?.content) {
                const stats = this.calculateStats(result.data.content);
                this.updateStatusBar(
                    `${stats.chars} 字 | ${stats.words} 词 | ${stats.paragraphs} 段`
                );
                // 保存详细统计供点击查看
                this.detailedStats = stats;
            }
        } catch (error) {
            console.error("[WordCount] 统计失败:", error);
            this.updateStatusBar("统计失败");
        }
    }

    /**
     * 计算文本统计
     */
    calculateStats(markdown) {
        // 移除Markdown标记后计算
        const plainText = markdown
            .replace(/```[\s\S]*?```/g, "")  // 移除代码块
            .replace(/`[^`]+`/g, "")          // 移除行内代码
            .replace(/!\[.*?\]\(.*?\)/g, "") // 移除图片
            .replace(/\[.*?\]\(.*?\)/g, "$1") // 链接只保留文本
            .replace(/[#*_~\[\]]/g, "")      // 移除格式标记
            .replace(/\n+/g, "\n")            // 合并空行
            .trim();

        // 字符数（不含空格）
        const chars = plainText.replace(/\s/g, "").length;
        
        // 中文词数估算（中文每个字算一个词），英文按空格分词
        const chineseChars = (plainText.match(/[\u4e00-\u9fa5]/g) || []).length;
        const englishWords = (plainText.match(/[a-zA-Z]+/g) || []).length;
        const words = chineseChars + englishWords;
        
        // 段落数
        const paragraphs = plainText.split(/\n+/).filter(p => p.trim()).length;
        
        // 行数
        const lines = markdown.split(/\n/).length;
        
        // 阅读时间估算（中文300字/分钟，英文200词/分钟）
        const readingMinutes = Math.ceil((chineseChars / 300) + (englishWords / 200));

        return {
            chars,
            words,
            paragraphs,
            lines,
            chineseChars,
            englishWords,
            readingMinutes
        };
    }

    /**
     * 更新状态栏显示
     */
    updateStatusBar(text) {
        const textEl = this.statusBarElement?.querySelector(".wordcount-text");
        if (textEl) {
            textEl.textContent = text;
        }
    }

    /**
     * 获取当前编辑器
     */
    getCurrentProtyle() {
        // 尝试从全局获取当前活动的protyle
        const layouts = window.siyuan?.layout?.centerLayout;
        if (!layouts) return null;
        
        // 递归查找活动的编辑器
        const findActiveEditor = (layout) => {
            if (layout.children) {
                for (const child of layout.children) {
                    const result = findActiveEditor(child);
                    if (result) return result;
                }
            }
            if (layout.model?.editor?.protyle) {
                return layout.model.editor.protyle;
            }
            return null;
        };
        
        return findActiveEditor(layouts);
    }

    /**
     * 显示详细统计对话框
     */
    async showDetailedStats() {
        if (!this.detailedStats) {
            showMessage("暂无统计数据，请先打开文档", 2000);
            return;
        }

        const stats = this.detailedStats;
        const message = `
📊 **文档统计详情**

| 项目 | 数量 |
|------|------|
| 总字符数 | ${stats.chars} |
| 总词数 | ${stats.words} |
| 中文字符 | ${stats.chineseChars} |
| 英文单词 | ${stats.englishWords} |
| 段落数 | ${stats.paragraphs} |
| 总行数 | ${stats.lines} |
| 预计阅读 | ${stats.readingMinutes} 分钟 |
        `.trim();

        // 使用confirm显示统计信息
        await confirm(
            "📊 文档统计",
            `<div style="font-family: monospace; line-height: 1.8;">
                <p><strong>总字符:</strong> ${stats.chars}</p>
                <p><strong>总词数:</strong> ${stats.words}</p>
                <p><strong>中文字符:</strong> ${stats.chineseChars}</p>
                <p><strong>英文单词:</strong> ${stats.englishWords}</p>
                <p><strong>段落数:</strong> ${stats.paragraphs}</p>
                <p><strong>总行数:</strong> ${stats.lines}</p>
                <p><strong>预计阅读:</strong> ${stats.readingMinutes} 分钟</p>
            </div>`
        );
    }
}
```

## 使用说明

1. **设置属性**：
   - 打开此文档，按 `Ctrl+Shift+A` 或点击右上角 `···` → `属性`
   - 添加自定义属性：
     - `ext-type` = `plugin`
     - `ext-lang` = `js`

2. **启用插件**：
   - 右键点击文档树中的此文档
   - 选择"注册为笔记内插件"
   - 插件将自动加载并在状态栏显示字数统计

3. **查看统计**：
   - 状态栏右侧会显示简要统计：`123 字 | 45 词 | 6 段`
   - 点击状态栏统计区域可查看详细信息

4. **禁用插件**：
   - 在插件管理界面禁用即可
