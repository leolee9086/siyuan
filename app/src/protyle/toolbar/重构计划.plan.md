## 拆分计划

### 第一阶段：拆分 `showRender` (378行 → 最高优先级)

`showRender` 是最大的方法，包含：
- HTML 模板生成
- 事件处理 (click, input, keydown)
- 内部函数 (`autoHeight`, `exportImg`, `subElementCloseCB`)

#### 拆分方案

1. **[NEW] `showRender.types.ts`** - 类型定义
   - `IRenderPanelOptions` 接口

2. **[NEW] `showRender.template.ts`** - HTML 模板生成
   - `生成渲染面板HTML(options)` 函数

3. **[NEW] `showRender.handlers.ts`** - 事件处理器
   - `处理头部按钮点击(event, context)`
   - `处理文本输入(event, context)`
   - `处理键盘事件(event, context)`
   - `导出为图片(renderElement, msgId)`

4. **[NEW] `showRender.utils.ts`** - 辅助函数
   - `计算面板高度(textElement, subElement, nodeRect, types)`
   - `确定渲染标题(types, subtype)` - 返回 title 和 placeholder

5. **[NEW] `showRender.closeCB.ts`** - 关闭回调
   - `创建关闭回调(options)` 函数

---

### 第二阶段：拆分 `showTpl` (190行)

#### 拆分方案

1. **[NEW] `showTpl.template.ts`** - 模板面板 HTML
   - `生成模板面板HTML()`

2. **[NEW] `showTpl.handlers.ts`** - 事件处理器
   - `处理模板搜索(value, listElement, previewElement, protyle)`
   - `处理模板选择(path, protyle, nodeElement)`
   - `处理模板删除(iconElement, listElement, previewElement, protyle)`

---

### 第三阶段：拆分 `showCodeLanguage` (149行)

#### 拆分方案

## 注意事项

1. **每次拆分后都要验证**
   - 运行 lint 检查
   - 运行 TypeScript 编译
   - 对比 `index.old.ts` 确认逻辑一致

2. **保持向后兼容**
   - 公共 API 不变
   - 只重构内部实现

3. **命名规范**
   - 文件名使用小驼峰 + 功能描述
   - 函数名使用中文，清晰表达功能
   - 类型定义使用 `I` 前缀

4. **依赖管理**
   - 避免循环依赖
   - 公共工具函数放到 `util.ts`
