# TikTokTac - Dialog 模块

### 🕒 Tik (应当做的)
- [ ] 优化消息提示（Toast）在大批量弹出时的堆叠显示效果。
- [ ] 确保所有的对话框在 Esc 按下时都有标准的关闭行为。
- [ ] **智能工具箱对话框 (Smart Toolbox)** [Desktop Only]
    - **正式设计方案**: [[docs/智能工具箱设计方案.md]] (已建立)
    - **核心特性**: CAD 式图标阵列、上下文感知的 Trigger 图标、左右键动作链分发。

### 💡 Tok (正在考虑的)
- [ ] 引入“对话框队列”机制，防止多个模态窗同时弹出的冲突。
- [ ] 支持对话框的“最小化”到状态栏功能。
- [ ] **表单化对话框生成器**：提供简单的 JSON 配置或声明式 API，快速生成带有输入检查、提交校验的标准化表单对话框，减少手动拼装 HTML 的坏味道。
- [ ] **语义化状态驱动**：目前的 Dialog 销毁逻辑较为分散，考虑通过简单的状态机管理（如 `opening -> visible -> closing -> destroyed`）来统一处理复杂的动画和并发请求。
- [ ] **全局上下文切换感知 (Global Context Change)**
    - **核心逻辑**：参考插件系统的 `EventBus`，定义一个全局事件，用于向“智能工具箱”分发当前环境。
    - **上下文数据结构 (Context Metadata)**：
        - `targetBlock`: 当前光标所在的 DOM 块（含 `data-node-id`, `data-type`）。
        - `selection`: 当前选中的文本范围或块集合。
        - `activeProtyle`: 当前活跃的编辑器实例。
        - `wndLayout`: 当前所在窗口的布局位置。
    - **工具箱响应式 UI**：工具箱监听此事件，实时计算各 Trigger 图标的“可用性”和“权重”，实现类似 CAD 的“根据环境弹出一组最可能用到的命令”。
    - **动作链 (Action Chain)**：
        - `PrimaryAction` (左键): 基于当前块执行插入、替换等常规操作。
        - `SecondaryAction` (右键): 基于当前块执行属性修改（IAL设置）、样式调整等 meta 操作。

### 🚀 Tak (远期计划)

- [ ] 协同确认机制：支持多人在同一个对话框上同步进行配置修改。
