# 修复Webpack构建中的大整数字面量错误

## 问题描述
构建过程中出现错误：`Big integer literals are not available in the configured target environment ("es2015")`

## 问题分析
1. 错误发生在 `@huggingface/transformers` 库的文件中
2. 该库使用了大整数字面量（ES2020特性）
3. 发现配置不一致问题：
   - webpack.config.js 中 target 设置为 "es2021"
   - webpack.desktop.js 中 target 设置为 "es6" (对应ES2015)
   - webpack.mobile.js 中 target 设置为 "es6" (对应ES2015)
   - webpack.export.js 中 target 设置为 "es6" (对应ES2015)

## 解决方案
1. 统一所有webpack配置文件中的target设置为"es2020"或更高版本
2. 确保所有构建步骤使用一致的目标环境以支持大整数字面量

## 实施步骤
1. 修复webpack.desktop.js中的target设置
2. 修复webpack.mobile.js中的target设置
3. 修复webpack.export.js中的target设置
4. 测试构建是否成功

## 结果
✅ 已成功修复所有webpack配置文件中的target设置，从"es6"更新为"es2020"
✅ 构建测试通过，大整数字面量错误已解决
✅ 现在只有一个关于import.meta的警告，这是另一个独立问题
