# 最小化跨设备边界传输 - 技术计划

## 📋 项目概述

### 🎯 核心目标
通过优化CPU-GPU之间的数据传输，显著提升WebGPU去雾算法的性能，减少内存带宽占用，降低延迟。

### 📊 当前问题分析
基于对现有代码的分析，发现以下数据传输瓶颈：

1. **频繁的CPU-GPU传输**：
   - 每个计算步骤都需要将中间结果传回CPU
   - 大气光估计需要CPU排序和查找
   - 引导滤波的多次均值计算产生大量传输

2. **内存分配开销**：
   - 每次计算都创建新的GPUBuffer
   - 缺乏内存复用机制
   - 纹理创建和销毁频繁

3. **计算分散化**：
   - 暗通道、透射率、引导滤波分别计算
   - 无法利用GPU的并行计算优势
   - 内核启动次数过多

## 🏗️ 技术架构设计

### 1. 流水线化处理架构

```
输入图像 → GPU内存池 → 流水线计算 → 结果输出
    ↓           ↓           ↓           ↓
  GPUTexture  内存复用   连续计算    单次传输
```

**核心组件**：
- `PipelineManager`: 管理整个计算流水线
- `MemoryPool`: GPU内存池管理
- `ComputePipeline`: 合并的计算着色器
- `AsyncQueue`: 异步计算队列

## 🔧 技术实现细节

### 1. 内存池实现细节

#### 1.1 缓冲区池管理
```javascript
class BufferPool {
  constructor(device, maxPoolSize = 10) {
    this.device = device;
    this.pools = new Map(); // 按大小和用途分类
    this.maxPoolSize = maxPoolSize;
  }
  
  getBuffer(size, usage) {
    const key = `${size}_${usage}`;
    if (!this.pools.has(key)) {
      this.pools.set(key, []);
    }
    
    const pool = this.pools.get(key);
    if (pool.length > 0) {
      return pool.pop();
    }
    
    return this.device.createBuffer({ size, usage });
  }
  
  returnBuffer(buffer, size, usage) {
    const key = `${size}_${usage}`;
    if (!this.pools.has(key)) {
      this.pools.set(key, []);
    }
    
    const pool = this.pools.get(key);
    if (pool.length < this.maxPoolSize) {
      pool.push(buffer);
    } else {
      buffer.destroy();
    }
  }
}
```

#### 1.2 纹理池管理
```javascript
class TexturePool {
  constructor(device, maxPoolSize = 5) {
    this.device = device;
    this.pools = new Map(); // 按尺寸和格式分类
    this.maxPoolSize = maxPoolSize;
  }
  
  getTexture(width, height, format = 'rgba8unorm') {
    const key = `${width}x${height}_${format}`;
    if (!this.pools.has(key)) {
      this.pools.set(key, []);
    }
    
    const pool = this.pools.get(key);
    if (pool.length > 0) {
      return pool.pop();
    }
    
    return this.device.createTexture({
      size: { width, height },
      format,
      usage: GPUTextureUsage.TEXTURE_BINDING | GPUTextureUsage.COPY_DST
    });
  }
  
  returnTexture(texture, width, height, format) {
    const key = `${width}x${height}_${format}`;
    if (!this.pools.has(key)) {
      this.pools.set(key, []);
    }
    
    const pool = this.pools.get(key);
    if (pool.length < this.maxPoolSize) {
      pool.push(texture);
    } else {
      texture.destroy();
    }
  }
}
```

fn fusedDehaze(@builtin(global_invocation_id) id: vec3<u32>) {
  let pixelCoord = vec2<i32>(id.xy);
  
  // 边界检查
  if (pixelCoord.x >= i32(uniforms.width) || pixelCoord.y >= i32(uniforms.height)) {
    return;
  }
  
  // 步骤1: 计算暗通道
  let darkChannel = computeDarkChannel(pixelCoord);
  
  // 步骤2: 估计透射率
  let transmission = estimateTransmission(darkChannel);
  
  // 步骤3: 简化引导滤波
  let refinedTransmission = simplifiedGuidedFilter(transmission, pixelCoord);
  
  // 步骤4: 恢复图像
  let result = recoverImage(pixelCoord, refinedTransmission);
  
  // 直接写入结果

}

### 3. 异步计算优化

#### 3.1 多队列并行处理
```javascript
class AsyncComputeManager {
  constructor(device) {
    this.device = device;
    this.computeQueue = device.createCommandEncoder();
    this.transferQueue = device.createCommandEncoder();
    this.syncPoints = new Set();
  }
  
  async executeAsync(computeCommands, transferCommands) {
    // 并行提交计算和传输命令
    const computePass = this.computeQueue.beginComputePass();
    computeCommands(computePass);
    computePass.end();
    
    const transferPass = this.transferQueue.beginRenderPass();
    transferCommands(transferPass);
    transferPass.end();
    
    // 并行提交
    this.device.queue.submit([
      this.computeQueue.finish(),
      this.transferQueue.finish()
    ]);
    
    // 等待完成
    await this.device.queue.onSubmittedWorkDone();
  }
}
```
