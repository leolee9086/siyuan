# 图像去雾算法演示

这是一个基于Vue 3和Vite的图像去雾算法演示应用，展示了两种不同的去雾算法实现。

## 功能特性

- 🖼️ **图像上传**: 支持拖拽上传和点击选择图片
- 🔧 **参数调节**: 实时调节算法参数，查看效果
- ⚡ **双算法支持**: 
  - 暗通道先验算法 (DCP) - 来自 `src/1.js`
  - 增强版算法 - 来自 `src/dehazing.js`
- 📊 **实时统计**: 显示处理时间、图像尺寸等信息
- 🎨 **现代化UI**: 响应式设计，支持移动端

## 算法参数说明

### 基础参数
- **窗口大小 (Patch Size)**: 暗通道计算窗口大小，影响去雾效果
- **去雾强度 (Omega)**: 控制去雾强度，值越大去雾效果越强
- **最小透射率 (T0)**: 防止过度去雾的参数

### 滤波参数
- **引导滤波半径 (Radius)**: 引导滤波的半径参数
- **正则化参数 (Epsilon)**: 防止数值不稳定的正则化参数

## 使用方法

1. **启动开发服务器**:
   ```bash
   pnpm dev
   ```

2. **访问应用**: 打开浏览器访问 `http://localhost:3000`

3. **上传图片**: 点击上传区域或拖拽图片到页面

4. **选择算法**: 在顶部标签页选择要使用的算法

5. **调节参数**: 使用滑块调节各种参数

6. **开始处理**: 点击"开始处理"按钮

7. **查看结果**: 对比原始图像和处理后的图像

## 技术栈

- **前端框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **样式**: CSS3 (响应式设计)
- **算法**: 原生JavaScript实现
