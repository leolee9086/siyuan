提交的commit必须说明以下内容:

意图:说明修改的背景和意图,不超过100字

修改概要:以极其简略的语言说明代码修改总结,不超过20字

commit必须以意图为单位提交,禁止在没有阅读修改内容时提交

禁止在同一个提交中包含不同意图的修改

正确的范例:

```txt
git commit -m "更新规则文档,加强对AI的git操作的约束"
```

典型错误-冗余的抬头:

```
git commit -m "意图: 添加git提交消息规范并修复规则文件重复内容

修改概要: 添加提交规范修复重复"
```

典型错误-没有提供任何新信息

```
git commit -m "意图: 改进规范

修改概要: 添加提交规范修复重复"
```
